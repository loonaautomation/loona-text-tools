متن / Markdown سے EPUB - اپنی EPUB ای بک بنائیں

مختصراً: سادہ متن یا Markdown پیسٹ یا اپ لوڈ کریں، عنوان اور مصنف شامل کریں، اور درست EPUB ای بک ڈاؤن لوڈ کریں - درست ساخت (mimetype پہلے اور غیر دبا، کنٹینر، پیکیج فائل، نیویگیشن اور NCX)، ابواب Markdown سرخیوں پر تقسیم، بنیادی Markdown فارمیٹنگ (سرخیاں، بولڈ، اٹالک، فہرستیں اور پیراگراف) محفوظ۔ نتیجہ ہمارے اپنے EPUB Reader اور معیاری ای بک ریڈرز میں کھلتا ہے۔

مصنفین، اساتذہ اور طلبہ کے پاس اکثر تیار متن ہوتا ہے مگر ای بک نہیں۔ یہ بلڈر اس متن کو اصل EPUB میں بدلتا ہے - نام بدلی zip نہیں - بالکل ان اصولوں سے جن کی ای بک ریڈرز توقع کرتے ہیں، مکمل طور پر آپ کے آلے پر۔

بنائے گئے ابواب

    ڈیزائن سے نجی: اس ٹول میں سب کچھ JavaScript کے ساتھ آپ کے براؤزر میں 100% ہوتا ہے۔ آپ کی فائلیں کبھی سرور پر اپ لوڈ نہیں ہوتیں، کبھی ذخیرہ نہیں ہوتیں اور ہم کبھی نہیں دیکھتے - ٹیب بند کریں اور سب ختم۔ DRM سے محفوظ کتابیں تبدیل نہیں ہو سکتیں اور نہیں ہوں گی۔

    اس ٹول کا استعمال کیسے کریں

    1. اپنا متن پیسٹ کریں خانے میں، یا اپ لوڈ کریں ایک .txt / .md فائل (20 MB تک)۔
    2. شامل کریں ایک عنوان اور، اگر آپ چاہیں، ایک مصنف۔ .md متن کے لیے Markdown پر نشان برقرار رکھیں: # اور ## سرخیاں نئے ابواب شروع کرتی ہیں۔ سادہ متن کے لیے ابواب ان سطروں سے شروع ہوتے ہیں جیسے “Chapter 2” اور پیراگراف خالی سطروں سے الگ ہوتے ہیں۔
    3. کلک کریں EPUB بنائیں & ڈاؤن لوڈ کریں، ابواب کی فہرست دیکھیں، اور فائل کسی بھی EPUB ریڈر میں کھولیں - بشمول ہمارے مفت EPUB Reader کے۔

    یہ کیسے کام کرتا ہے

    بنکر EPUB کو واحد اس ترتیب سے جوڑتا ہے جس کی معیار اجازت دیتا ہے: mimetype اندراج زپ میں پہلے اور بغیر کمپریس جاتا ہے، پھر META-INF/container.xml جو پیکیج فائل (OPF) کی طرف اشارہ کرتا ہے جس میں عنوان، مصنف، مینی فیسٹ اور پڑھنے کی ترتیب (spine) ہوتی ہے۔ یہ EPUB 3 نیویگیشن دستاویز اور پرانی NCX فہرستِ مضامین دونوں لکھتا ہے تاکہ پرانے اور نئے ریڈرز دونوں کام کریں، جمع ایک عنوان صفحہ اور فی باب ایک XHTML فائل۔ Markdown محفوظ طریقے سے تبدیل ہوتا ہے - آپ کا متن پہلے escape ہوتا ہے، پھر سرخیاں، بولڈ، اٹالک، فہرستیں، اقتباسات اور پیراگراف صاف XHTML میں بدلے جاتے ہیں۔

    حل شدہ مثال

    ایک استاد Markdown میں لکھی 6 ابواب کی کلاس ریڈر پیسٹ کرتا ہے، اسے “Class 6 Geography Notes” عنوان دیتا ہے، اور ایک EPUB ڈاؤن لوڈ کرتا ہے۔ طلبہ اسے اپنے فونز پر Loona EPUB Reader میں کھولتے ہیں - ابواب کی فہرست، سرخیاں اور بولڈ اہم اصطلاحات سب برقرار۔

    اکثر پوچھے گئے سوالات

    کیا یہ متن سے EPUB کنورٹر مفت ہے؟

    جی ہاں - مکمل طور پر مفت، کوئی سائن اپ نہیں، کوئی اکاؤنٹ نہیں اور کوئی حد نہیں۔

    کیا میرا متن سرور پر اپ لوڈ ہوتا ہے؟

    نہیں۔ EPUB 100% آپ کے براؤزر میں JavaScript سے بنتا ہے۔ آپ کا متن کبھی آپ کے آلے سے باہر نہیں جاتا اور ہمارے پاس کبھی محفوظ نہیں ہوتا۔

    ابواب کا فیصلہ کیسے ہوتا ہے؟

    Markdown موڈ میں # یا ## سے شروع ہونے والی سطریں نیا باب شروع کرتی ہیں۔ سادہ متن موڈ میں 'Chapter 2' جیسی سطریں نیا باب شروع کرتی ہیں اور پیراگراف خالی سطروں سے الگ ہوتے ہیں؛ باب والی سطریں نہ ہوں تو پورا متن ایک باب بن جاتا ہے۔

    کون سی Markdown سپورٹ ہوتی ہے؟

    سرخیاں (ابواب کے اندر ## اور نیچے، باب کے وقفوں کے طور پر # / ##)، بولڈ، اٹالک، گولی والی اور نمبر شدہ فہرستیں، بلاک کوٹس، ان لائن کوڈ اور سادہ ویب لنکس۔ پیچیدہ جدول اور تصاویر سپورٹ نہیں ہوتیں۔

    کیا EPUB اصل ریڈرز میں کھلے گی؟

    جی ہاں۔ یہ EPUB ساخت کی پیروی کرتا ہے - mimetype پہلے اور غیر دبائی ذخیرہ، container.xml، OPF مینی فیسٹ اور اسپائن، EPUB 3 نیویگیشن پلس NCX - اور اس سائٹ پر ہمارے اپنے EPUB Reader میں کھلنے کے لیے آزمایا گیا ہے۔

    سائز کی حد کیا ہے؟
