Editor Metadata EPUB - Edit Judul, Penulis & Detail Ebook

Singkatnya: pilih EPUB bebas DRM untuk melihat dan mengedit metadatanya - judul, penulis, bahasa, penerbit dan deskripsi - dan untuk melihat informasi sampulnya (file sampul dan jenis, dengan pratinjau) - dan secara opsional ganti gambar sampul dengan JPG atau PNG Anda sendiri. Menyimpan mengunduh EPUB baru dengan bab dan sampul yang sama dan metadata paket (OPF) yang dikoreksi; entri mimetype tetap pertama dan tanpa kompresi. File asli Anda tidak pernah diubah, dan buku yang dilindungi DRM tidak akan diedit.

Judul yang salah, penulis yang hilang atau deskripsi yang kosong membuat buku sulit ditemukan di aplikasi perpustakaan mana pun. Editor ini membaca file paket buku, memungkinkan Anda memperbaiki kolom-kolom itu dengan benar, dan membangun kembali EPUB yang valid di sekitar bab-bab yang tidak tersentuh.

🏷️
Letakkan file .epub Anda di sini, atau klik untuk memilihnya

Buku hingga 20 MB. File diproses hanya di perangkat ini - tidak ada yang diunggah.

Informasi sampul ditampilkan di atas. Anda juga dapat mengunggah sampul JPG atau PNG baru: itu menggantikan sampul yang dinyatakan buku - atau menambahkan satu, dengan halaman sampul dan entri panduan yang benar, jika buku tidak memilikinya. Bab tidak pernah ditulis ulang dan DRM tidak pernah disentuh. Mengosongkan kolom akan menghapus kolom opsional itu (judul tidak boleh kosong).

Privat berdasarkan desain: semuanya dalam alat ini terjadi 100% di browser Anda dengan JavaScript. File Anda tidak pernah diunggah ke server, tidak pernah disimpan dan tidak pernah dilihat oleh kami - tutup tab dan semuanya hilang. Buku yang dilindungi DRM tidak dapat dan tidak akan dikonversi.

Cara menggunakan alat ini

  1. Klik kotak di atas (atau seret dan letakkan) dan pilih yang bebas DRM .epub file hingga 20 MB.
  2. Tinjau informasi dan pratinjau sampul, lalu edit kolom judul, penulis, bahasa, penerbit, atau deskripsi.
  3. Klik Simpan EPUB yang Diedit & Unduh - file baru menyimpan setiap bab persis seperti aslinya.

Cara kerjanya

Setiap EPUB membawa file paket (OPF) yang menyimpan metadata resminya sebagai kolom Dublin Core. Alat ini menggunakan parser teruji yang sama seperti Pembaca EPUB kami untuk menemukan file itu, menampilkan kolomnya dan gambar sampul yang dinyatakan, dan - saat Anda menyimpan - menulis ulang hanya kolom metadata tersebut, mengescapenya dengan aman sebagai XML. Buku kemudian dizip ulang sesuai aturan EPUB: entri mimetype pertama dan disimpan tanpa kompresi, setiap file lain (bab, gambar, gaya) disalin byte demi byte.

Contoh yang dikerjakan

Seorang guru menerima bacaan hasil konversi pindaian berjudul “untitled-document-3”. Dalam satu menit ia mengatur judul sebenarnya, sekolahnya sebagai penerbit dan deskripsi satu baris, menyimpan, dan buku itu sekarang tersusun dengan benar di aplikasi pembaca setiap siswa.

Pertanyaan yang Sering Diajukan

Apakah editor metadata EPUB ini gratis?

Ya - sepenuhnya gratis, tanpa pendaftaran, tanpa akun dan tanpa batas.

Apakah ebook saya diunggah ke server?

Tidak. File dibaca dan dibangun kembali 100% di browser Anda dengan JavaScript. Tidak pernah meninggalkan perangkat Anda dan tidak pernah disimpan oleh kami.

Apakah mengedit metadata akan mengubah bab atau sampul saya?

Tidak. File bab, gambar dan gaya disalin byte demi byte; hanya kolom metadata dalam file paket yang berubah. Gambar sampul itu sendiri ditampilkan sebagai referensi dan tidak diganti.

Mengapa buku saya tidak dapat dibuka untuk diedit? (DRM)

Sebagian besar ebook yang dibeli dari toko seperti Kindle, Kobo atau Apple Books dilindungi oleh DRM. Alat ini tidak akan mengedit buku yang dilindungi DRM, dan tidak menghapus atau membobol DRM.

Berapa batas ukuran file?

Buku hingga 20 MB ditangani di browser. File yang lebih besar mendapatkan pesan yang jelas alih-alih hasil yang rusak.
