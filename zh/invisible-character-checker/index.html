隐形字符检查器 - 看见您看不见的字符

简而言之: 隐形字符检查器扫描您的文本寻找隐藏字符——零宽空格、字节顺序标记、不间断空格和方向覆盖——列出它们确切藏在哪里,并一键删除它们全部。

复制的文本常常偷偷带上隐形乘客:网页上的零宽空格、Word 中的不间断空格、双语文档中的方向标记。它们会以看似魔术的方式破坏搜索、密码、代码和表单提交。在下方粘贴您的文本,查看每个隐藏字符的名称和位置。

以隐私为设计: 这个工具中的一切都 100% 在您的浏览器中用 JavaScript 进行。您的文本从未被上传到服务器、从未被存储、从未被我们看到——关闭标签页,一切都消失了。

如何使用隐形字符检查器

  1. 粘贴可疑文本——来自网页、PDF、Word 或聊天消息。
  2. 阅读报告:找到的每个隐形字符、它叫什么、它的 Unicode 代码以及它在您文本中的位置。
  3. 点击“删除所有隐形字符”就地清理文本,然后把它复制回属于它的地方。

它如何工作

Unicode 包含许多不占可见空间的字符:零宽空格(U+200B)从网页溜进来,字节顺序标记(U+FEFF)随保存的文件一起旅行,不间断空格(U+00A0)来自文字处理软件,看起来恰好和普通空格一样,但在精确搜索时会失败,方向标记(U+202A-U+202E)从乌尔都语/阿拉伯语和英语混合文本中溜进来,甚至能重新排列您看到的内容。检查器逐字符地遍历您的文本,将每个字符与已知的不可见代码点列表匹配,并报告每个命中的位置。清理时将不间断空格替换为普通空格,并删除其余部分。

实例

一个复制的优惠券代码在结账时一直失败。检查器在第 7 个位置发现了一个零宽空格,是从网页粘贴进来的。一键将其删除——代码就能用了。

常见问题

这个隐形字符检查器免费吗?

是的——完全免费,无需注册,没有限制。

为什么隐形字符重要?

它们让看起来相同的文本在精确匹配时失败——登录、优惠券代码、搜索、话题标签和代码在隐藏字符位于内部时都会中断。

零宽空格从哪里来?

主要是复制粘贴:内容管理系统、聊天应用和文档把它们作为换行提示插入,它们随您的文本隐形地一起旅行。

我的文本会被上传到任何地方吗?

不会。扫描 100% 在您的浏览器中进行——您的文本永远不会离开您的设备。

清理会改变我的文本外观吗?

不会——这正是关键所在。只有隐形字符被删除(不间断空格变成普通空格),因此可见文本保持完全相同。
