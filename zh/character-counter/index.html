字符计数器 - 含空格与不含空格

简而言之: 字符计数器确切显示您的文本有多少字符——含空格、不含空格——以及在帖子和短信等常见限制中还剩多少空间。

一篇文章只超了三个字符、一条短信悄悄变成两条、一段元描述在单词中间被截断——字符限制无处不在。在下方输入,实时查看每个计数和剩余限额的更新。

以隐私为设计: 这个工具中的一切都 100% 在您的浏览器中用 JavaScript 进行。您的文本从未被上传到服务器、从未被存储、从未被我们看到——关闭标签页,一切都消失了。

如何使用字符计数器

  1. 把您的文本输入或粘贴到框中。
  2. 检查实时计数:含空格的字符、不含空格的字符和单词。
  3. 留意限制跟踪器——绿色表示有余量,或确切显示您必须删减多少字符。

它如何工作

工具统计每个字符,包括空格和换行,然后还统计删除所有空白后的文本。对于短信,它应用真实的网络规则:单条消息容纳 160 个字符,更长的文本以每段 153 个字符的链接分段发送——这就是为什么 161 字符的消息花费双倍。X 帖子(280)、短信(160)、元标题(60)、元描述(160)和 LinkedIn 帖子(3,000)的限制跟踪器会随着您的输入而更新。

实例

您的产品公告有 173 个字符。计数器显示短信跟踪器为 '2 segments',X 跟踪器还剩 107 个字符——因此您把文本缩短到 158 个字符,它又能放进一个短信分段了。

常见问题

字符计数器免费吗?

是的——100% 免费,无需注册,您粘贴的内容没有字符限制。

为什么空格在短信中计数,却不是到处都计数?

短信和 X 计算每个字符,包括空格。一些学校和考试表格要求不含空格的计数,因此我们两者都显示。

为什么 161 字符的短信算作 2 条消息?

长短信被拆分为 153 字符的分段,带有链接头,因此 161 个字符需要两个分段,并按两条消息计费。

它能正确统计表情符号吗?

大多数表情符号在 JavaScript 和 X 上算作 2 个字符——计数器遵循同样的规则,因此您看到的与平台计数的相符。

我的文本会被存储吗?

不会。所有计数都在您的设备上的浏览器中进行。
