文本倒序 - 字母、单词或整行

简而言之: 文本倒序器以四种不同的方式翻转您的文本:全文向后、每个单词反向拼写、词序倒转或行序倒转。

倒序后的文本对谜题、社交帖子、检查回文和俏皮消息很实用。选择您想要的倒序方式——每种模式给出不同的结果,而且全都只需一键。

以隐私为设计: 这个工具中的一切都 100% 在您的浏览器中用 JavaScript 进行。您的文本从未被上传到服务器、从未被存储、从未被我们看到——关闭标签页,一切都消失了。

如何使用文本倒序

  1. 把您的文本输入或粘贴到框中。
  2. 选择一种倒序类型——全文、每个单词、词序或行序。
  3. 点击“文本倒序”。再次点击会倒回原文。

它如何工作

全文倒序翻转每个字符,包括空格和换行,而且对符号安全:表情符号和带重音字母被视为单个字符,永远不会被拆成破碎的两半。'每个单词向后' 保持单词在原位,但把每个单词反向拼写。'词序' 保持每个单词拼写正确,但反转它们在每行中的顺序,'行序' 则将行从上到下翻转——对把倒计时变成正计数很有用。

实例

从 'the cat sat' 开始。全文向后:'tas tac eht'。每个单词向后:'eht tac tas'。词序倒转:'sat cat the'。一个短句子的三种不同谜题。

常见问题

文本倒序器免费吗?

是的——完全免费,无需注册。

我可以撤销倒序吗?

是的——这里的每次倒序都是它自己的撤销。再次应用相同的模式,您会确切拿回原文。

它适用于表情符号吗?

是的。字符按完整符号倒序,因此表情符号和带重音字母在翻转中完好无损。

什么是回文检查?

回文正读反读都一样,比如“madam”。使用“全文”模式将您的词倒序并进行比较。

我的文本会被上传吗?

不会——一切都发生在您的浏览器中。
