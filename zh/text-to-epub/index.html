文本/Markdown 转 EPUB - 制作您自己的 EPUB 电子书

简而言之: 粘贴或上传纯文本或 Markdown,添加标题和作者,下载一本有效的 EPUB 电子书——结构正确(mimetype 在最前面且不压缩、容器、包文件、导航和 NCX),章节按 Markdown 标题拆分,基本 Markdown 格式(标题、粗体、斜体、列表和段落)得以保留。结果能在我们自己的 EPUB 阅读器和标准电子书阅读器中打开。

作家、教师和学生常常有完成的文本,却没有电子书。这个构建器把该文本变成真正的 EPUB——不是改名的 zip——使用电子书阅读器期望的确切规则,完全在您的设备上。

已创建的章节

    以隐私为设计: 这个工具中的一切都 100% 在您的浏览器中用 JavaScript 进行。您的文件从未被上传到服务器、从未被存储、从未被我们看到——关闭标签页,一切都消失了。受 DRM 保护的书籍不能也不会被转换。

    如何使用此工具

    1. 粘贴您的文本 到框中,或上传一个 .txt / .md 文件(最多 20 MB)。
    2. 添加一个 标题 以及,如果您愿意,一个 作者。对于 .md 文本,保持勾选 Markdown: # 和 ## 标题会开启新章节。对于纯文本,章节从类似 “Chapter 2” 的行开始,段落之间以空行分隔。
    3. 点击 构建 EPUB 并下载,查看章节列表,并在任何 EPUB 阅读器中打开文件——包括我们免费的 EPUB 阅读器。

    它如何工作

    构建器按标准允许的唯一顺序组装 EPUB:mimetype 条目首先且不压缩地进入 zip,然后是指向包文件(OPF)的 META-INF/container.xml,其中包含标题、作者、清单和阅读顺序(书脊)。它同时写 EPUB 3 导航文档和较旧的 NCX 目录,因此新旧阅读器都能工作,外加一个标题页和每章一个 XHTML 文件。Markdown 会被安全转换——您的文本先被转义,然后标题、粗体、斜体、列表、引用和段落被转换成干净的 XHTML。

    实例

    一位教师粘贴了一本用 Markdown 写的 6 章课堂读物,标题定为 “Class 6 Geography Notes”,下载成一个 EPUB。学生在手机上的 Loona EPUB 阅读器中打开它——章节列表、标题和粗体关键词全部完好。

    常见问题

    这个文本转 EPUB 转换器免费吗?

    是的——完全免费,无需注册,没有账户,没有限制。

    我的文本会被上传到服务器吗?

    不会。EPUB 100% 在您的浏览器中用 JavaScript 构建。您的文本永远不会离开您的设备,也永远不会被我们存储。

    章节是如何决定的?

    在 Markdown 模式下,以 # 或 ## 开头的行会开启新章节。在纯文本模式下,像 'Chapter 2' 这样的行开启新章节,段落以空行分隔;如果没有章节行,整段文本就成为一章。

    支持哪些 Markdown?

    标题(章节内的 ## 及以下,# / ## 作为章节分隔)、粗体、斜体、项目符号和编号列表、块引用、行内代码和简单的网页链接。不支持复杂表格和图片。

    EPUB 会在真正的阅读器中打开吗?

    是的。它遵循 EPUB 结构——mimetype 在最前面且不压缩存储、container.xml、OPF 清单和书脊、EPUB 3 导航加 NCX——并经过测试,能在本网站我们自己的 EPUB 阅读器中打开。

    大小限制是多少?

    不超过 20 MB 的文本或文件在浏览器中处理;更大的输入会得到一条明确消息。
