EPUB 阅读器 - 在线打开并阅读 EPUB 电子书

简而言之: 从您的设备选择一本 EPUB 电子书,就在您的浏览器中阅读它——带章节列表、可调文本大小和夜间阅读的深色主题。文件在您自己的设备上打开,从未上传到任何地方。一个诚实的限制:受 DRM 保护的电子书(从 Kindle、Kobo 或 Apple 商店购买的大多数书籍)无法打开,因为本阅读器不删除或破解 DRM。

EPUB 是世界上最常见的电子书格式,被公共图书馆、Project Gutenberg 和亚马逊之外的大多数书店使用。直到现在,您都需要一个专门的应用才能打开它。在这里您只需选择文件:阅读器会当场解包,列出章节,显示书内的图片,让您在任何手机、平板或电脑上舒适地阅读。

如何使用EPUB 阅读器

  1. 点击上方框(或拖放)并选择一个 .epub 来自您设备的文件。
  2. 阅读器显示书名、作者和章节列表。从列表中选择任何章节即可直接跳到它。
  3. 使用 上一章/下一章 通读这本书的按钮, A− / A+ 来改变文本大小,以及 深色 夜间阅读按钮。
  4. 完成后,直接关闭标签页——或使用“关闭书籍”打开另一本电子书。

它如何工作

EPUB 文件实际上是一个压缩成一个文件的小型网站:一组用 XHTML 编写的章节,加上图片和一幅书籍地图。本阅读器在您的浏览器中解压文件,读取地图(称为 OPF 的包文件)以找到书名、作者和正确的章节顺序,并读取目录——EPUB 3 的导航文档,或 EPUB 2 书籍中较旧的 NCX 文件。然后每章在显示前都会被清理:脚本和任何可能运行代码或向外连接的内容都会被剥离,而书籍自己的图片则从文件内部安全加载。由于一切都在本地运行,即使是一部长篇小说也能在一两秒内打开。

实例

您从 Project Gutenberg 下载了一部免费的公有领域小说,在这里打开它。阅读器显示标题和作者,列出所有 24 章,并打开第 1 章。在公共汽车上,您点“下一章”继续阅读,放大一次文本,并在外面变暗时打开深色主题——没有安装应用,没有创建账户,文件从未离开您的手机。

常见问题

这个 EPUB 阅读器免费吗?

是的——完全免费,无需注册,没有账户,对您打开多少本电子书没有限制。

我的电子书会被上传到服务器吗?

不会。文件 100% 在您的浏览器中用 JavaScript 打开和读取。它永远不会离开您的设备,永远不会被我们存储,而且在页面加载后即使您离线也能工作。

为什么我的电子书无法打开?(DRM)

从 Kindle、Kobo 或 Apple Books 等商店购买的大多数电子书都受 DRM(复制保护)保护。本阅读器无法打开受 DRM 保护的文件,也不会删除或破解 DRM。无 DRM 的 EPUB 文件——例如来自 Project Gutenberg 的公有领域书籍或出版商以无 DRM 形式出售的书籍——可以正常打开。

支持哪些 EPUB 版本?

EPUB 2 和 EPUB 3 都支持。阅读器能理解 EPUB 3 导航文档和较旧的 EPUB 2 NCX 文件,并显示存储在书内的图片。

我可以在手机或平板上阅读吗?

是的。阅读器完全响应式,您可以在任何屏幕尺寸上放大文本并切换到深色主题,舒适地夜间阅读。
