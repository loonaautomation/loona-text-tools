Conversor de Texto para Binário - E de Volta Outra Vez

Em resumo: o conversor de Texto para Binário transforma as suas palavras nos 0 e 1 que os computadores salvam realmente - e transforma código binário de volta em texto legível.

Cada letra num tela é salva como números, e cada número como binário - apenas 0 e 1. Os estudantes de informática encontram isto no primeiro dia. Escreva texto para ver a sua verdadeira forma binária, ou cole binário para descodificar uma mensagem que alguém lhe enviou.

Privado por design: tudo nesta ferramenta acontece 100% no seu navegador com JavaScript. O seu texto nunca é carregado para um servidor, nunca é salvo e nunca é visto por nós - feche a aba e tudo desaparece.

Como usar Texto para Binário

  1. Escreva texto normal, ou cole código binário (grupos de 8 bits, espaços opcionais).
  2. Clique na direção de conversão que pretende.
  3. Copie o resultado - o binário faz uma divertida mensagem em código secreto para amigos e alunos.

Como funciona

Os computadores salvam texto como bytes usando a codificação UTF-8: cada carácter torna-se um ou mais bytes, e cada byte é escrito com exatamente 8 dígitos binários. 'A' é o byte 65, escrito 01000001. As letras inglesas ocupam um byte cada; as letras urdu ocupam dois bytes cada, razão pela qual o seu binário parece mais longo - a ferramenta trata ambas corretamente nas duas direções e valida o binário colado antes de descodificar, para que um dígito perdido dê um erro claro em vez de disparates.

Exemplo resolvido

'Hi' torna-se '01001000 01101001': H é o byte 72 e i é o byte 105. Cole esse binário na ferramenta e clique em Binário → Texto, e 'Hi' regressa.

Perguntas Frequentes

O conversor binário é gratuito?

Sim - grátis, sem registro, conversões ilimitadas.

Porque tem cada letra 8 dígitos?

O texto é salvo em bytes, e um byte são 8 bits (0 e 1). Cada grupo de 8 dígitos é um byte - um carácter simples.

Suporta urdu e emoji?

Sim - usa UTF-8 completo, por isso as letras urdu (2 bytes cada) e os emoji (até 4 bytes) convertem-se corretamente nos dois sentidos.

Posso colar binário sem espaços?

Sim - os espaços são ignorados; os dígitos são simplesmente agrupados em 8 a partir do início.

O meu texto é carregado?

Não - a conversão acontece 100% no seu navegador.
