Inverter Texto - Letras, Palavras ou Linhas Inteiras

Em resumo: o Inversor de Texto vira o seu texto de quatro formas diferentes: o texto inteiro ao contrário, cada palavra soletreada ao contrário, a ordem das palavras invertida, ou a ordem das linhas invertida.

O texto invertido é útil para puzzles, publicações sociais, verificar palíndromos e mensagens divertidas. Escolha o tipo de inversão que pretende - cada modo dá um resultado diferente, e todos são um clique.

Privado por design: tudo nesta ferramenta acontece 100% no seu navegador com JavaScript. O seu texto nunca é carregado para um servidor, nunca é salvo e nunca é visto por nós - feche a aba e tudo desaparece.

Como usar Inverter Texto

  1. Escreva ou cole o seu texto na caixa.
  2. Escolha um tipo de inversão - texto inteiro, cada palavra, ordem das palavras ou ordem das linhas.
  3. Clique em Reverse Text. Clicar outra vez inverte de volta para o original.

Como funciona

A inversão do texto inteiro inverte cada carácter incluindo espaços e quebras de linha, e é segura para símbolos: emoji e letras acentuadas são tratados como caracteres únicos, nunca partidos em metades quebradas. 'Each word backwards' mantém as palavras no lugar, mas soletra cada uma ao contrário. 'Word order' mantém cada palavra escrita corretamente, mas inverte a sua sequência em cada linha, e 'Line order' inverte as linhas de cima para baixo - útil para transformar uma contagem decrescente numa crescente.

Exemplo resolvido

Comece com 'the cat sat'. Texto inteiro ao contrário: 'tas tac eht'. Cada palavra ao contrário: 'eht tac tas'. Ordem das palavras invertida: 'sat cat the'. Três puzzles diferentes a partir de uma frase curta.

Perguntas Frequentes

O inversor de texto é gratuito?

Sim - completamente grátis, sem registro.

Posso anular uma inversão?

Sim - cada inversão aqui é o seu próprio desfazer. Aplique o mesmo modo outra vez e recupera o texto original exatamente.

Funciona com emoji?

Sim. Os caracteres são invertidos por símbolos inteiros, por isso os emoji e as letras acentuadas sobrevivem à inversão intactos.

O que é uma verificação de palíndromo?

Um palíndromo lê-se da mesma forma de trás para a frente, como 'madam'. Inverta a sua palavra com o modo 'Whole text' e compare.

O meu texto é carregado?

Não - tudo acontece no seu navegador.
