Conversor de Texto para Hexadecimal - Hexadecimal, Feito Corretamente

Em resumo: o Conversor de Texto para Hexadecimal transforma qualquer texto em bytes hexadecimais e converte hexadecimal de volta em texto, usando codificação UTF-8 real para que os caracteres não-ingleses sobrevivam à viagem de ida e volta.

Hex é a forma como os computadores mostram bytes em bruto: cores, ficheiros, memória e dados de rede falam todos esta linguagem. Escreva texto abaixo para o ver como hex, ou cole hex para ler o que diz. Ao contrário dos conversores ingénuos, este codifica UTF-8 corretamente, por isso letras como "é", a escrita urdu e até emoji convertem-se corretamente.

Privado por design: tudo nesta ferramenta acontece 100% no seu navegador com JavaScript. O seu texto nunca é carregado para um servidor, nunca é guardado e nunca é visto por nós - feche o separador e tudo desaparece.

Como usar o Conversor de Texto para Hexadecimal

  1. Escreva ou cole texto simples e clique em "Text to Hex" - cada byte aparece como dois dígitos hexadecimais.
  2. Escolha se os bytes são separados por espaços, prontos para colar em código ou num editor hexadecimal.
  3. Para descodificar, cole hex (com ou sem espaços) e clique em "Hex to Text" - o UTF-8 é remontado para os caracteres originais.

Como funciona

Hexadecimal conta em base 16, usando dígitos 0-9 e letras A-F, por isso um byte (0-255) é sempre exatamente dois dígitos hexadecimais: "A" é o byte 65, escrito 41 em hex. O texto torna-se bytes através da codificação UTF-8: as letras inglesas simples ocupam um byte cada, os caracteres acentuados e urdu ocupam dois ou três, e os emoji ocupam quatro. O conversor usa o codificador e descodificador UTF-8 incorporados no seu navegador - os mesmos sobre os quais a própria web funciona - por isso o que codificar aqui descodifica de forma idêntica em qualquer lugar.

Exemplo resolvido

"Hi" codifica para 48 69. A letra urdu "ا" (U+0627) codifica para D8 A7 - dois bytes - e descodificar D8 A7 devolve a letra diretamente, algo que os conversores simples apenas ASCII erram.

Perguntas Frequentes

Este conversor hexadecimal é gratuito?

Sim - completamente grátis, sem registo e sem limite.

Porque produzem alguns caracteres mais de dois pares hexadecimais?

Porque o UTF-8 usa mais bytes para eles: as letras inglesas ocupam 1 byte, as letras urdu e acentuadas normalmente 2-3 bytes, os emoji 4 bytes. Cada byte é um par hexadecimal.

Posso descodificar hexadecimal sem espaços?

Sim - espaços, vírgulas e quebras de linha são todos ignorados, por isso 4869 e 48 69 descodificam ambos para "Hi".

O meu texto é carregado para algum lugar?

Não. A conversão acontece 100% no seu navegador - o seu texto nunca sai do seu dispositivo.

E se o meu hex for inválido?

O descodificador indica o problema em vez de adivinhar - o hex tem de conter um número par de dígitos 0-9 e A-F.
