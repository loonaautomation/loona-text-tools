Loona Text Tools の仕組み

  1. ツールを選んでテキストを追加してください。 入力する、貼り付ける、話す - あなたの言葉はあなた自身のブラウザーでだけ読まれます。
  2. オプションを調整してください。 ケーススタイル、並べ替え順、制限、音声はすべてあなたの制御下にあります。
  3. 結果をコピーまたはダウンロードしてください。 結果はあなたの端末に即座に表示されます - どこにでもコピーするか、ファイルとして保存してください。

なぜ人々はブラウザーベースのツールを信頼しますか？

ほとんどのオンラインテキストサイトは、あなたの文章 — エッセイ、手紙、ビジネス文書、プライベートなメモ — を見知らぬ人のサーバーに送るよう求めます。Loona Text Tools は逆の方法で構築されています：処理コードがあなたのテキストのところに来ます。その逆ではありません。その意味は、より速い結果、どこでも機能するプライバシー、あなたのものが何も保存、記録、共有されないことです。タブを閉じれば、あなたの言葉の痕跡はすべて消えます。

よくある質問

Loona Text Tools は本当に無料ですか？

はい - すべてのツールは100%無料で、登録不要、透かしなし、私たちが課す一日の制限もありません。

私のテキストはあなたのサーバーにアップロードされますか？

決してありません。すべてのツールはブラウザーで100%動作します。あなたの言葉は最初から最後まであなたの端末に留まります - それが全体の設計です。

どの端末に対応していますか？

携帯電話、タブレット、コンピューターのどの現代ブラウザーでも — Chrome、Edge、Firefox、Safari はすべて動作します。音声ツールは Chrome と Edge で最もよく動作します。

ツールはオフラインで動作しますか？

ツールページが読み込まれれば、接続が切れてもほとんどすべてが動作します。それはすべてローカルで行われるからです。（一部のブラウザーの音声認識には接続が必要です。）

なぜローマ字ウルドゥーからウルドゥーへの変換ツールですか？

Loona はパキスタンで構築されており、何百万人もの人々が毎日英語の文字でウルドゥー語を入力します。Loona Automation の使命 - Bolti Duniya - は、書くことと読むことが、すべての言語で、すべての人に開かれるべきだということです。
