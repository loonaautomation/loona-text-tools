不可視文字チェッカー - 見えない文字を見る

要するに： 不可視文字チェッカーは、テキストをスキャンして隠れた文字 — ゼロ幅スペース、バイト順マーク、改行しないスペース、方向の上書き — を探し、それらが隠れる正確な場所を一覧表示し、ワンクリックですべて削除します。

コピーされたテキストはしばしば不可視の乗客を密輸入します：Web ページからのゼロ幅スペース、Word からの改行しないスペース、二言語文書からの方向マーク。それらは、魔法のように見える方法で検索、パスワード、コード、フォーム送信を壊します。下にテキストを貼り付けると、すべての隠れた文字に名前と場所が表示されます。

設計によるプライバシー： このツールのすべては、JavaScript でブラウザーで100%行われます。あなたのテキストがサーバーにアップロードされたり、保存されたり、私たちに見られたりすることは決してありません - タブを閉じればすべて消えます。

不可視文字チェッカーの使い方

  1. 疑わしいテキストを貼り付けてください - Web ページ、PDF、Word、チャットメッセージから。
  2. レポートを読んでください：見つかった各不可視文字、その名前、Unicode コード、テキスト内での位置。
  3. 「すべての不可視文字を削除」をクリックしてテキストをその場でクリーニングし、属する場所にコピーし戻してください。

仕組み

Unicode には、目に見えるスペースを占めない文字が多く含まれます：ゼロ幅スペース（U+200B）は Web ページから滑り込み、バイト順マーク（U+FEFF）は保存されたファイルから乗ってきて、改行しないスペース（U+00A0）はワープロから来て、通常のスペースと正確に同じに見えますが正確な検索で失敗します。そして方向マーク（U+202A-U+202E）は、混合したウルドゥー／アラビア語と英語のテキストから忍び込み、見えるものを並べ替えることさえあります。チェッカーはテキストを文字ごとに歩き、それぞれ既知の不可視コードポイントのリストと照合し、すべてのヒットの位置を報告します。クリーニングは改行しないスペースを通常のスペースに置き換え、残りを削除します。

実例

コピーしたクーポンコードが決済で何度も失敗します。チェッカーは、Web ページから貼り付けられた位置7のゼロ幅スペースを見つけます。ワンクリックで削除すると、コードが機能します。

よくある質問

この不可視文字チェッカーは無料ですか？

はい - 完全に無料、登録不要、制限なし。

なぜ不可視文字が重要ですか？

それらは、同一に見えるテキストを正確な一致で失敗させます — ログイン、クーポンコード、検索、ハッシュタグ、コードはすべて、隠れた文字が中にあると壊れます。

ゼロ幅スペースはどこから来ますか？

ほとんどはコピー＆ペーストです：コンテンツ管理システム、チャットアプリ、文書は、それらを行区切りのヒントとして挿入し、それらはあなたのテキストとともに不可視のまま移動します。

私のテキストはどこかにアップロードされますか？

いいえ。スキャンはブラウザーで100%行われます - あなたのテキストが端末から離れることは決してありません。

クリーニングで私のテキストの見た目が変わりますか？

いいえ - それが目的です。不可視文字だけが削除されます（改行しないスペースは通常のスペースになります）ので、見えるテキストは正確に同じままです。
