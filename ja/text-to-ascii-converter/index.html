テキストから ASCII への変換ツール - あなたの文字の背後にあるコード

要するに： テキストから ASCII への変換ツールは、テキストのすべての文字の数値コードを — 十進数、十六進数、八進数、二進数で — 表示し、ASCII コードのリストを読み取り可能なテキストに戻します。

画面上のすべての文字は数字として保存されます："A" は 65、"a" は 97、スペースは 32 です。プログラマー、学生、パズル制作者はそれらの数字を常に必要とします。下にテキストを入力するとそのコードが表示され、コードを貼り付けると、その中に隠れたテキストを読めます。

設計によるプライバシー： このツールのすべては、JavaScript でブラウザーで100%行われます。あなたのテキストがサーバーにアップロードされたり、保存されたり、私たちに見られたりすることは決してありません - タブを閉じればすべて消えます。

テキストから ASCII への変換ツールの使い方

  1. プレーンテキストを入力または貼り付けて「テキストから ASCII コードへ」をクリックすると、すべての文字の十進数、十六進数、八進数、二進数の値が表で表示されます。
  2. 十進数コードも結果ボックスに一覧表示され、コピーの準備ができます。
  3. 代わりにデコードするには、スペースで区切られた十進コード（72 101 108 108 111 のように）を貼り付けて「ASCII コードからテキストへ」をクリックしてください。

仕組み

ASCII（American Standard Code for Information Interchange）は、すべての一般的な文字に 0 から 127 までの番号を与えます：数字 0-9 はコード 48-57、大文字は 65-90、小文字は 97-122 を占め、一般的な記号が隙間を埋めます。プレーン ASCII を超える文字 — アクセント付き文字、ウルドゥー文字、絵文字 — はより広い Unicode 標準を使い、このツールはそれらのコードポイントも報告し、127 を超えるものには Unicode とラベルを付けます。デコードは単に各番号を引いて文字をつなぎ直すだけです。

実例

"Hi!" と入力すると、表は H = 72（十六進数 48、バイナリ 1001000）、i = 105（十六進数 69）、! = 33（十六進数 21）と表示します。"72 105 33" をデコーダーに貼り付けると "Hi!" が直ちに戻ってきます。

よくある質問

この ASCII 変換ツールは無料ですか？

はい - 完全に無料、登録不要、制限なし。

ASCII と Unicode の違いは何ですか？

ASCII は128文字をカバーします — 英語の文字、数字、一般的な記号です。Unicode はすべての書記体系と絵文字をカバーします。その最初の128コードポイントはちょうど ASCII のものと同じですので、ASCII テキストは有効な Unicode です。

デコーダーはどのコードを受け入れますか？

スペース、カンマ、改行で区切られた十進数。0 から 1114111 まで（完全な Unicode 範囲）。

私のテキストはどこかにアップロードされますか？

いいえ。変換はブラウザーで100%行われます - あなたのテキストが端末から離れることは決してありません。

なぜ大文字と小文字は異なるコードを持ちますか？

それらは表の中で異なる文字です — "A" は 65、"a" は 97、正確に 32 離れています。これはプログラマーが何十年もケースを反転させるために使ってきた癖です。
