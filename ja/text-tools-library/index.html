単語カウンター - 単語、文字＆読書時間を数える

要するに： 単語カウンターは、入力するとテキストの単語、文字、文、段落を数え、それを声に出して読んだり話したりするのにどれくらいかかるかを見積もります。

エッセイ、スピーチ、ブログ記事、申請フォームにはすべて単語制限があります。下にテキストを貼り付けるか入力すると、すべてのカウントがライブで更新されます — 押すボタンはなく、何もアップロードされず、読書時間と話す時間の見積もりが、プレゼンテーションや動画の計画に役立ちます。

テキストツールライブラリ
