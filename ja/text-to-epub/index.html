テキスト / Markdown から EPUB へ - あなた自身の EPUB 電子書籍を作る

要するに： プレーンテキストまたは Markdown を貼り付けるかアップロードし、タイトルと著者を追加し、有効な EPUB 電子書籍をダウンロードしてください - 正しい構造（mimetype が最初で非圧縮、コンテナ、パッケージファイル、ナビゲーションと NCX）、Markdown 見出しで分割された章、基本的な Markdown 書式（見出し、太字、イタリック、リスト、段落）が保持されます。結果は当サイト自身の EPUB リーダーと標準の電子書籍リーダーで開きます。

ライター、教師、学生は、完成したテキストはあるが電子書籍がないことがよくあります。この構築ツールは、そのテキストを本物の EPUB に変えます — 名前を変えた zip ではありません — 電子書籍リーダーが期待する正確なルールを使って、完全にあなたの端末で。

作成された章

    設計によるプライバシー： このツールのすべては、JavaScript でブラウザーで100%行われます。あなたのファイルがサーバーにアップロードされたり、保存されたり、私たちに見られたりすることは決してありません - タブを閉じればすべて消えます。DRM で保護された書籍は変換できず、変換されません。

    このツールの使い方

    1. テキストを貼り付け ボックスの中へ、または次をアップロードしてください .txt / .md ファイル（最大 20 MB）。
    2. 次を追加 タイトル そして、気に入れば、 著者。Markdown は .md テキスト用にチェックしたままにしてください： # と ## の見出しが新しい章の始まりになります。プレーンテキストの場合、章は “Chapter 2” のような行から始まり、段落は空行で区切られます。
    3. クリック EPUB を構築＆ダウンロード、章リストを確認し、任意の EPUB リーダーでファイルを開いてください。当サイトの無料 EPUB リーダーでも開けます。

    仕組み

    構築ツールは、標準が許す唯一の順序で EPUB を組み立てます：mimetype エントリが zip に最初に圧縮されずに入り、次にタイトル、著者、マニフェスト、読書順（背表紙）を持つパッケージファイル（OPF）を指す META-INF/container.xml が入ります。EPUB 3 のナビゲーション文書と古い NCX 目次の両方を書きますので、新旧両方のリーダーが動作します。さらに、タイトルページと章ごとに一つの XHTML ファイルも書きます。Markdown は安全に変換されます - あなたのテキストはまずエスケープされ、次に見出し、太字、イタリック、リスト、引用、段落がきれいな XHTML に変えられます。

    実例

    ある教師が Markdown で書かれた6章のクラスリーダーを貼り付け、“Class 6 Geography Notes” というタイトルを付けて、一つの EPUB をダウンロードします。学生は携帯電話の Loona EPUB リーダーでそれを開きます — 章リスト、見出し、太字の重要用語はすべてそのままです。

    よくある質問

    このテキストから EPUB への変換ツールは無料ですか？

    はい - 完全に無料、登録不要、アカウントなし、制限なし。

    私のテキストはサーバーにアップロードされますか？

    いいえ。EPUB は JavaScript でブラウザーで100%構築されます。あなたのテキストが端末から離れることは決してなく、私たちが保存することも決してありません。

    章はどのように決まりますか？

    Markdown モードでは、# または ## で始まる行が新しい章を始めます。プレーンテキストモードでは、'Chapter 2' のような行が新しい章を始め、段落は空行で区切られます。章の行がない場合、テキスト全体が一つの章になります。

    どの Markdown に対応していますか？

    見出し（章の中では ## 以下、章の区切りとして # / ##）、太字、イタリック、箇条書きと番号付きリスト、ブロック引用、インラインコード、単純な Web リンク。複雑な表と画像には対応していません。

    EPUB は本物のリーダーで開きますか？

    はい。EPUB の構造に従います — mimetype が最初で非圧縮で保存され、container.xml、OPF マニフェストと背表紙、EPUB 3 ナビゲーション＋NCX — そしてこのサイトの当サイト自身の EPUB リーダーで開けることがテストされています。

    サイズの制限は何ですか？

    最大 20 MB までのテキストまたはファイルはブラウザーで処理されます。より大きな入力には明確なメッセージが表示されます。
