Traducteur de code Morse - Avec un vrai son

En bref : le Traducteur de code Morse convertit le texte en code Morse points-et-tirets (et retour), et peut jouer le code à voix haute comme de vrais bips.

Le code Morse a transporté les messages du monde pendant plus d’un siècle - et les scouts, les amateurs de radio et les créateurs de puzzles l’utilisent encore chaque jour. Tapez du texte pour obtenir son code, collez du code pour lire un message, et appuyez sur Lecture pour entendre exactement comment il sonne.

Privé par conception : tout dans cet outil se passe à 100 % dans votre navigateur avec JavaScript. Votre texte n’est jamais téléchargé sur un serveur, jamais stocké et jamais vu par nous - fermez l’onglet et tout a disparu.

Comment utiliser le Traducteur de code Morse

  1. Tapez du texte brut, ou collez du code Morse (points, tirets, espaces entre les lettres, / entre les mots).
  2. Cliquez sur la direction que vous voulez - Texte vers Morse, ou Morse vers Texte.
  3. Appuyez sur Jouer le son Morse pour entendre le code biper à un rythme régulier et apprenable.

Comment ça fonctionne

Chaque lettre et chaque chiffre a un motif Morse international officiel - S est trois points, O est trois tirets, ce qui explique pourquoi SOS (··· --- ···) est devenu l’appel de détresse mondial. Le traducteur associe chaque caractère à son motif, en joignant les lettres par des espaces et les mots par une barre oblique. Le lecteur utilise l’audio de votre appareil pour biper un point pour une unité, un tiret pour trois unités, avec une unité de silence entre les symboles - les vraies règles de synchronisation que les opérateurs radio apprennent.

Exemple travaillé

Type 'HELLO' and you get '.... . .-.. .-.. ---'. Paste '... --- ...' the other way and you get 'SOS' - the most famous three letters in Morse history.

Questions fréquemment posées

Le traducteur Morse est-il gratuit ?

Oui - gratuit, sans inscription, utilisation illimitée.

Comment écrire le code Morse dans la saisie ?

Points et tirets pour chaque lettre, un espace entre les lettres, et ‘ / ’ entre les mots - par exemple : .... .. / - .... . .-. . signifie ‘HI THERE’.

Inclut-il les nombres et la ponctuation ?

Oui - tous les chiffres et les signes de ponctuation courants (point, virgule, point d’interrogation, apostrophe, barre oblique, crochets, deux-points et plus) suivent la norme internationale.

Peut-il jouer le son de n’importe quel texte ?

Oui - convertissez d’abord le texte en Morse, puis appuyez sur Lecture pour l’entendre.

Quelque chose est-il téléchargé ?

Non - la traduction et le son se font entièrement dans votre navigateur.
