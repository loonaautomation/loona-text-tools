Tradutor de Código Morse - Com Som Real

Em resumo: o Tradutor de Código Morse converte texto em código Morse de pontos e traços (e de volta), e pode reproduzir o código em voz alta como sons autênticos.

O código Morse transportou as mensagens do mundo durante mais de um século - e escuteiros, entusiastas de rádio e criadores de puzzles ainda o usam diariamente. Escreva texto para obter o seu código, cole código para ler uma mensagem e prima Play para ouvir exatamente como soa.

Privado por design: tudo nesta ferramenta acontece 100% no seu navegador com JavaScript. O seu texto nunca é carregado para um servidor, nunca é guardado e nunca é visto por nós - feche o separador e tudo desaparece.

Como usar o Tradutor de Código Morse

  1. Escreva texto simples, ou cole código Morse (pontos, traços, espaços entre letras, / entre palavras).
  2. Clique na direção que pretende - Texto para Morse, ou Morse para Texto.
  3. Prima Play Morse Sound para ouvir o código emitido a um ritmo estável e aprendível.

Como funciona

Cada letra e dígito tem um padrão Morse internacional oficial - S são três pontos, O são três traços, razão pela qual SOS (··· --- ···) se tornou o sinal de socorro do mundo. O tradutor mapeia cada carácter para o seu padrão, juntando letras com espaços e palavras com uma barra. O reprodutor usa o áudio do seu dispositivo para emitir um ponto de uma unidade, um traço de três unidades, com uma unidade de silêncio entre símbolos - as regras de temporização reais que os operadores de rádio aprendem.

Exemplo resolvido

Escreva 'HELLO' e obtém '.... . .-.. .-.. ---'. Cole '... --- ...' ao contrário e obtém 'SOS' - as três letras mais famosas da história Morse.

Perguntas Frequentes

O tradutor Morse é gratuito?

Sim - grátis, sem registo, utilização ilimitada.

Como escrevo código Morse na introdução?

Pontos e traços para cada letra, um espaço entre letras e ' / ' entre palavras - por exemplo: .... .. / - .... . .-. . significa 'HI THERE'.

Inclui números e pontuação?

Sim - todos os dígitos e os sinais de pontuação comuns (ponto final, vírgula, ponto de interrogação, apóstrofo, barra, parênteses, dois pontos e mais) seguem o padrão internacional.

Pode reproduzir o som de qualquer texto?

Sim - converta primeiro o texto para Morse, depois prima Play para o ouvir.

Alguma coisa é carregada?

Não - a tradução e o som acontecem inteiramente no seu navegador.
