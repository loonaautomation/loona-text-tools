Sobre o Loona Text Tools

Em resumo: O Loona Text Tools é um conjunto gratuito de 22 ferramentas de texto da Loona Automation que funciona inteiramente no seu navegador - as suas palavras nunca são carregadas para lado nenhum.

O que é o Loona Text Tools?

O Loona Text Tools é uma coleção gratuita de 22 ferramentas online para o trabalho quotidiano com palavras: contar palavras e caracteres, converter caixa, remover linhas duplicadas, ordenar, inverter, limpar espaços, localizar e substituir, ouvir texto em voz alta, ditar por voz, gerar palavras-passe fortes, comparar textos, contar a frequência de palavras, juntar linhas quebradas, numerar linhas, gerar texto de preenchimento e slugs de URL, conversão de código Morse e binário, um conversor de urdu romano para escrita urdu, um bloco de notas com gravação automática e um gerador de texto decorativo para redes sociais. Faz parte de Loona Automation, uma família de ferramentas web gratuitas de resolução de problemas, criada para estudantes, professores, escritores, freelancers, escritórios e pequenas empresas - no Paquistão e em todo o mundo.

A Nossa Diferença: Privacidade por Design

Quase todos os websites de texto funcionam enviando a sua escrita para um servidor. Nós construímos o oposto: todo o processamento acontece dentro do seu próprio navegador com JavaScript. O seu texto nunca é transmitido, nunca é guardado e nunca é visto por nós. É mais rápido, funciona em qualquer dispositivo e é simplesmente a forma respeitosa de tratar as palavras das pessoas.

A Nossa Missão

A missão da Loona Automation - "Bolti Duniya" - é que cada livro deve falar, em cada língua, para todos os que não sabem ler. As nossas ferramentas de texto levam essa missão diretamente: um leitor de texto para voz para quem aprende a ouvir, um datilógrafo de voz para texto para quem não consegue escrever facilmente, e um conversor de urdu romano que transforma a escrita quotidiana em escrita urdu correta. Se uma ferramenta lhe poupar cinco minutos hoje, fez o seu trabalho.
