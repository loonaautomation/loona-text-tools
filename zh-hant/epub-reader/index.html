EPUB 閱讀器 - 線上開啟並閱讀 EPUB 電子書

簡而言之: 從您的裝置選擇一本 EPUB 電子書,就在您的瀏覽器中閱讀它——帶章節列表、可調文字大小和夜間閱讀的深色主題。檔案在您自己的裝置上開啟,從未上傳到任何地方。一個誠實的限制:受 DRM 保護的電子書(從 Kindle、Kobo 或 Apple 商店購買的大多數書籍)無法開啟,因為本閱讀器不刪除或破解 DRM。

EPUB 是世界上最常見的電子書格式,被公共圖書館、Project Gutenberg 和亞馬遜之外的大多數書店使用。直到現在,您都需要一個專門的應用才能開啟它。在這裡您只需選擇檔案:閱讀器會當場解包,列出章節,顯示書內的圖片,讓您在任何手機、平板或電腦上舒適地閱讀。

如何使用EPUB 閱讀器

  1. 點選上方框(或拖放)並選擇一個 .epub 來自您裝置的檔案。
  2. 閱讀器顯示書名、作者和章節列表。從列表中選擇任何章節即可直接跳到它。
  3. 使用 上一章/下一章 通讀這本書的按鈕, A− / A+ 來改變文字大小,以及 深色 夜間閱讀按鈕。
  4. 完成後,直接關閉標籤頁——或使用“關閉書籍”開啟另一本電子書。

它如何工作

EPUB 檔案實際上是一個壓縮成一個檔案的小型網站:一組用 XHTML 編寫的章節,加上圖片和一幅書籍地圖。本閱讀器在您的瀏覽器中解壓檔案,讀取地圖(稱為 OPF 的包檔案)以找到書名、作者和正確的章節順序,並讀取目錄——EPUB 3 的導航文件,或 EPUB 2 書籍中較舊的 NCX 檔案。然後每章在顯示前都會被清理:指令碼和任何可能執行程式碼或向外連線的內容都會被剝離,而書籍自己的圖片則從檔案內部安全載入。由於一切都在本地執行,即使是一部長篇小說也能在一兩秒內開啟。

例項

您從 Project Gutenberg 下載了一部免費的公有領域小說,在這裡開啟它。閱讀器顯示標題和作者,列出所有 24 章,並開啟第 1 章。在公共汽車上,您點“下一章”繼續閱讀,放大一次文字,並在外面變暗時開啟深色主題——沒有安裝應用,沒有建立賬戶,檔案從未離開您的手機。

常見問題

這個 EPUB 閱讀器免費嗎?

是的——完全免費,無需註冊,沒有賬戶,對您開啟多少本電子書沒有限制。

我的電子書會被上傳到伺服器嗎?

不會。檔案 100% 在您的瀏覽器中用 JavaScript 開啟和讀取。它永遠不會離開您的裝置,永遠不會被我們儲存,而且在頁面載入後即使您離線也能工作。

為什麼我的電子書無法開啟?(DRM)

從 Kindle、Kobo 或 Apple Books 等商店購買的大多數電子書都受 DRM(複製保護)保護。本閱讀器無法開啟受 DRM 保護的檔案,也不會刪除或破解 DRM。無 DRM 的 EPUB 檔案——例如來自 Project Gutenberg 的公有領域書籍或出版商以無 DRM 形式出售的書籍——可以正常開啟。

支援哪些 EPUB 版本?

EPUB 2 和 EPUB 3 都支援。閱讀器能理解 EPUB 3 導航文件和較舊的 EPUB 2 NCX 檔案,並顯示儲存在書內的圖片。

我可以在手機或平板上閱讀嗎?

是的。閱讀器完全響應式,您可以在任何螢幕尺寸上放大文字並切換到深色主題,舒適地夜間閱讀。
