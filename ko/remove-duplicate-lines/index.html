중복 줄 제거 - 고유한 줄만 유지

요컨대: Duplicate Line Remover는 텍스트를 줄별로 스캔하고 반복되는 모든 줄을 삭제해요. 각 고유한 줄을 원래 순서대로 한 번 유지해요.

병합된 목록, 복사한 등록부, 내보낸 데이터는 반복되는 줄로 가득해요. 텍스트를 붙여 넣고, 대문자와 엉뚱한 공백이 차이로 세어져야 하는지 선택하고, 클릭 한 번으로 깔끔한 고유 목록을 돌려받으세요.

설계상 비공개: 이 도구의 모든 것은 JavaScript로 브라우저에서 100% 일어나요. 텍스트는 서버에 업로드되지 않고, 저장되지 않고, 저희가 보지 않아요 - 탭을 닫으면 모든 것이 사라져요.

중복 줄 제거 사용 방법

  1. 텍스트나 목록을 상자에 붙여 넣으세요 - 한 줄에 항목 하나예요.
  2. 옵션을 설정하세요: 대문자와 가장자리 공백이 차이로 세어지는지, 빈 줄도 가는지를요.
  3. Remove Duplicates를 클릭하고 정리된 목록을 복사하거나 다운로드하세요.

작동 방식

도구는 텍스트를 줄별로 읽고 본 모든 줄을 기억해요. 줄이 처음 나타나면 유지돼요; 이후의 모든 반복은 삭제돼요. 대소문자 구분이 꺼져 있으면, 'Ali'와 'ali'는 같은 줄로 세어져요. 다듬기가 켜져 있으면, 가장자리 공백만 다른 줄도 중복으로 세어져요 - 유지된 줄은 다듬어진 형태로 표시돼요. 보고는 정확히 몇 줄이 제거됐는지 알려줘요.

작업 예시

수업 출석 내보내기에는 9줄이 있어요: Ali, Sara, Ali, Ahmed, sara, Ahmed, Usman, Ali, (빈칸). 기본 옵션을 사용하면 결과는 4줄 - Ali, Sara, Ahmed, Usman - 이 되고 도구는 'Removed 5 duplicate or empty lines'라고 보고해요.

자주 묻는 질문

이 도구가 무료인가요?

네 - 완전히 무료, 회원가입 없음, 수천 줄의 목록을 처리해요.

원래 순서를 유지하나요?

네. 유지된 줄은 처음 나타난 순서대로 남아요. 이후에 알파벳 순서가 필요하면 Sort Lines 도구를 사용하세요.

중복으로 세어지는 것은 무엇인가요?

이전 줄과 동일한 줄이에요. 대문자와 주변 공백이 중요한지 여부를 조절할 수 있어요.

줄 대신 중복 단어를 제거할 수 있나요?

단어 수준 개수는 Word Frequency 도구를 시도해 보세요. 모든 단어와 나타나는 횟수를 나열해요.

제 목록이 업로드되나요?

아니요 - 모든 것이 기기의 브라우저에서 실행돼요.
