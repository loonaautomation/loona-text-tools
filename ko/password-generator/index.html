비밀번호 생성기 - 강력하고 무작위

요컨대: Password Generator는 자신의 기기에서 강력한 무작위 비밀번호를 만들어요. 선택한 길이와 문자 유형으로요 - 어떤 것도 어디로 전송되지 않아요.

재사용되고 추측 가능한 비밀번호가 계정이 도난당하는 방식이에요. 길이를 설정하고, 문자 유형에 체크하고, 어떤 인간도 추측할 수 없는 비밀번호를 생성하세요 - 그런 다음 비밀번호 관리자에 바로 복사하세요. 언제든 새 배치를 생성하세요.

설계상 비공개: 이 도구의 모든 것은 JavaScript로 브라우저에서 100% 일어나요. 텍스트는 서버에 업로드되지 않고, 저장되지 않고, 저희가 보지 않아요 - 탭을 닫으면 모든 것이 사라져요.

비밀번호 생성기 사용 방법

  1. 길이를 밀어보세요 - 16자 이상이 강력한 기본값이에요; 길이가 복잡한 것보다 항상 나아요.
  2. 웹사이트가 허용하는 문자 유형에 체크하세요. 기호는 허용되는 곳에 강도를 더해요.
  3. Generate를 클릭한 다음, 상자의 비밀번호를 클릭하면 클립보드에 바로 복사돼요.

작동 방식

비밀번호는 브라우저의 암호화 무작위 생성기(crypto.getRandomValues)로 만들어져요 - 은행 앱이 의존하는 같은 품질의 무작위성이고, Math.random은 절대 아니에요. 생성된 모든 비밀번호는 체크한 각 유형에서 최소 하나의 문자를 포함하는 것이 보장되고, 나머지는 전체 풀에서 고르게 뽑혀 섞여요. 강도 측정기는 비밀번호의 엔트로피를 비트로 보여줘요: 검색 공간이 두 배가 될 때마다 한 비트가 추가되고, 70비트를 넘는 것은 실용적인 추측을 넘어서요. 비밀번호는 이 페이지에만 존재해요 - 저희는 보거나, 보내거나, 저장하지 않아요.

작업 예시

길이 16에 소문자 + 대문자 + 숫자 + 기호에 체크하면, 풀은 약 80자이고 엔트로피는 대략 101비트예요 - 도구는 'vR8$kQ2!mZx7&Lp4'를 만들 수 있어요. 초당 수십억 번의 추측도 인간의 일생에서는 흠집도 내지 못해요.

자주 묻는 질문

이 비밀번호 생성기는 안전한가요?

네. 비밀번호는 자신의 기기에서 암호화 무작위성으로 만들어지고 어디에도 전송되거나 저장되지 않아요.

비밀번호는 얼마나 길어야 하나요?

중요한 계정은 최소 14-16자예요. 길이가 복잡성보다 중요해요 - 긴 비밀번호가 짧고 영리한 것보다 나아요.

왜 기본적으로 l, 1, O, 0을 제외하나요?

비슷하게 생긴 문자는 비밀번호를 손으로 입력해야 할 때 입력 실수를 일으켜요. 사이트가 요구하거나 항상 붙여 넣으면 옵션에 체크하세요.

모든 계정마다 다른 비밀번호가 있어야 하나요?

물론이에요 - 그게 생성기의 핵심이에요. 비밀번호 관리자에 저장해서 마스터 비밀번호 하나만 기억하세요.

한 번에 여러 개를 생성할 수 있나요?

네 - 클릭할 때마다 다섯 개의 새로운 비밀번호가 만들어져서 좋아하는 것을 선택할 수 있어요.
