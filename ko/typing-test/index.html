타자 테스트 - 분당 단어 수로 속도 확인

요컨대: 분당 단어 수(WPM)로 속도, 정확도, 분당 문자 수(CPM)를 측정하는 무료 60초 타자 테스트예요 - 난이도를 선택하고, 입력을 시작하고, 점수가 실시간으로 쌓이는 것을 보세요.

타자는 매일 사용하는 기술이지만, 측정하는 사람은 거의 없어요. 아래에서 Easy, Medium, Hard를 선택하고, 입력 상자를 클릭하고 시작하세요 - 타이머는 첫 키 입력과 함께 시작돼요. 올바른 글자는 초록색으로, 실수는 빨간색으로 변하고, WPM, 정확도, CPM은 진행하는 동안 업데이트돼요.

설계상 비공개: 이 도구의 모든 것은 JavaScript로 브라우저에서 100% 일어나요. 입력한 것은 서버에 업로드되지 않고, 저장되지 않고, 저희가 보지 않아요 - 탭을 닫으면 모든 것이 사라져요. 테스트 중에는 붙여 넣기가 비활성화돼서 점수가 입력을 정직하게 반영해요.

타자 테스트 사용 방법

  1. 난이도를 선택하세요 - 워밍업에는 Easy, 숫자와 구두점을 섞고 싶으면 Hard예요.
  2. 입력 상자를 클릭하고 위에 표시된 텍스트를 입력하기 시작하세요. 60초 타이머는 첫 키 입력과 함께 자동으로 시작돼요.
  3. 실시간 수치를 보세요: 남은 시간, WPM, 정확도, CPM이에요. 초록 글자는 올바르고, 빨간 글자는 실수예요 - 원하면 백스페이스하고 고치세요.
  4. 시간이 끝나면 (또는 전체 텍스트를 마치면), 최종 결과가 나타나요. 같은 텍스트로 다시 시도하려면 Restart를 누르고, 새 텍스트는 Another text를 누르세요.

작동 방식

테스트는 입력하는 모든 문자를 샘플 텍스트와 위치별로 비교해요. 속도는 표준 타자 테스트 공식을 사용해요: WPM = (올바른 문자 ÷ 5) ÷ 분. 다섯으로 나누는 것은 공백을 포함해 다섯 문자를 하나의 "단어"로 취급하는 거예요. 수십 년 동안 타자 속도를 측정해 온 방식이라서, 점수를 다른 표준 테스트와 비교할 수 있어요. 정확도는 올바르게 입력한 문자의 비율이고, CPM은 단순히 분당 입력한 총 문자 수예요.

작업 예시

전체 60초 동안 입력하고 300자를 입력해요. 그 중 285개가 샘플과 일치해요. 정확도는 285 ÷ 300 = 95%예요. WPM은 (285 ÷ 5) ÷ 1분 = 57 WPM, 그리고 CPM은 300 ÷ 1 = 300 CPM. 같은 285개의 올바른 문자를 30초에 입력했다면 WPM은 두 배인 114가 됐을 거예요 - 속도와 정확도 모두 중요해요.

자주 묻는 질문

이 타자 테스트가 무료인가요?

네 - 완전히 무료, 회원가입 없음, 테스트를 볼 수 있는 횟수에 제한이 없어요.

WPM은 어떻게 계산되나요?

WPM은 표준 타자 테스트 공식을 사용해요: (입력한 올바른 문자 / 5) / 분이에요. 5로 나누는 것은 공백을 포함해 평균 단어를 다섯 문자로 취급해서, 점수를 테스트 간에 비교할 수 있어요.

좋은 타자 속도는 무엇인가요?

평균 성인은 약 40 WPM으로 입력해요. 사무직은 보통 50-80 WPM을 요청하고, 전문 타이피스트는 90-120 WPM에 도달해요. 95%를 넘는 정확도가 대부분의 진짜 작업에서 순수 속도보다 더 중요해요.

테스트가 휴대폰이나 태블릿에서 작동하나요?

네, 모든 최신 모바일 브라우저에서 작동해요. 키보드 속도의 진정한 측정을 위해, 물리적 키보드로 테스트를 보세요 - 화면 키보드는 자연히 점수가 낮아요.

입력한 것이 어디로 전송되나요?

아니요. 테스트는 브라우저에서 100% 실행돼요. 입력한 것은 업로드, 저장되지 않고 저희가 보지 않아요.
