텍스트 / Markdown을 EPUB로 - 자신의 EPUB 전자책 만들기

요컨대: 일반 텍스트나 Markdown을 붙여 넣거나 업로드하고, 제목과 저자를 추가하고, 유효한 EPUB 전자책을 다운로드하세요 - 올바른 구조(mimetype가 먼저이고 압축되지 않고, 컨테이너, 패키지 파일, 탐색과 NCX), Markdown 제목에서 나뉜 장, 기본 Markdown 서식(제목, 굵은, 이탤릭, 목록, 단락)이 유지돼요. 결과는 EPUB Reader와 표준 전자책 리더에서 열려요.

작가, 교사, 학생은 종종 완성된 텍스트는 있지만 전자책이 없어요. 이 빌더는 그 텍스트를 진짜 EPUB로 바꿔요 - 이름만 바꾼 zip이 아니라 - 전자책 리더가 기대하는 정확한 규칙을 사용해, 전적으로 기기에서요.

만든 장

    설계상 비공개: 이 도구의 모든 것은 JavaScript로 브라우저에서 100% 일어나요. 파일은 서버에 업로드되지 않고, 저장되지 않고, 저희가 보지 않아요 - 탭을 닫으면 모든 것이 사라져요. DRM으로 보호된 책은 변환할 수 없고 하지 않을 거예요.

    이 도구 사용 방법

    1. 텍스트를 붙여 넣으세요 상자에, 또는 업로드하세요 .txt / .md 파일 (최대 20 MB).
    2. 추가 제목 그리고, 원하면, 하나의 저자. .md 텍스트에는 Markdown에 체크를 유지하세요: #와 ## 제목이 새 장을 시작해요. 일반 텍스트에서는 “Chapter 2” 같은 줄에서 장이 시작되고 단락은 빈 줄로 구분돼요.
    3. 클릭 EPUB 만들기 & 다운로드, 장 목록을 확인하고, 모든 EPUB 리더에서 파일을 여세요 - 무료 EPUB Reader도 포함돼요.

    작동 방식

    빌더는 표준이 허용하는 유일한 순서로 EPUB를 조립해요: mimetype 항목이 먼저 압축되지 않은 상태로 zip에 들어가고, 그런 다음 제목, 저자, 매니페스트, 읽기 순서(spine)가 있는 패키지 파일(OPF)을 가리키는 META-INF/container.xml이에요. EPUB 3 탐색 문서와 오래된 NCX 목차를 모두 써서 오래된 리더와 새 리더가 모두 작동하고, 제목 페이지와 장마다 XHTML 파일 하나를 더해요. Markdown은 안전하게 변환돼요 - 텍스트가 먼저 이스케이프되고, 그런 다음 제목, 굵은, 이탤릭, 목록, 인용, 단락이 깔끔한 XHTML로 바뀌어요.

    작업 예시

    한 교사가 Markdown으로 쓴 6장짜리 수업 읽기자료를 붙여 넣고, 제목을 “Class 6 Geography Notes”로 정하고, EPUB 하나를 다운로드해요. 학생들은 휴대폰의 Loona EPUB Reader에서 열어요 - 장 목록, 제목, 굵은 핵심 용어가 모두 그대로예요.

    자주 묻는 질문

    이 텍스트를 EPUB로 변환기가 무료인가요?

    네 - 완전히 무료, 회원가입 없음, 계정 없음, 제한이 없어요.

    제 텍스트가 서버에 업로드되나요?

    아니요. EPUB는 JavaScript로 브라우저에서 100% 만들어져요. 텍스트가 기기를 떠나지 않고 저희가 저장하지 않아요.

    장은 어떻게 결정되나요?

    Markdown 모드에서는 # 또는 ##로 시작하는 줄이 새 장을 시작해요. 일반 텍스트 모드에서는 'Chapter 2' 같은 줄이 새 장을 시작하고 단락은 빈 줄로 구분돼요; 장 줄이 없으면 전체 텍스트가 하나의 장이 돼요.

    어떤 Markdown이 지원되나요?

    제목(장 안에서는 ## 이하, 장 구분으로는 # / ##), 굵은, 이탤릭, 글머리 기호와 번호 목록, 인용 블록, 인라인 코드, 간단한 웹 링크예요. 복잡한 표와 이미지는 지원되지 않아요.

    EPUB가 진짜 리더에서 열리나요?

    네. EPUB 구조를 따라요 - mimetype가 먼저이고 압축되지 않은 상태로 저장되고, container.xml, OPF 매니페스트와 spine, EPUB 3 탐색과 NCX - 그리고 이 사이트의 EPUB Reader에서 열리는 것을 테스트했어요.

    크기 제한은 무엇인가요?

    최대 20 MB 텍스트나 파일을 브라우저에서 처리해요; 더 큰 입력은 명확한 메시지를 받아요.
