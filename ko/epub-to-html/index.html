EPUB를 HTML로 - EPUB 전자책을 하나의 HTML 파일로 변환

요컨대: DRM 없는 EPUB를 선택하고 하나의 자체 포함 HTML 파일을 얻으세요: 깔끔한 기본 타이포그래피로 읽기 순서대로 장, 파일 안에 데이터 URI로 임베드된 작은 이미지, 누락된 파일을 가리키지 않도록 무력화된 내부 책 링크예요. 최대 20 MB 책; DRM으로 보호된 책은 변환할 수 없고 하지 않을 거예요.

하나의 HTML 파일은 책 장 집합을 공유하거나 보관하는 가장 쉬운 방법이에요: 모든 브라우저에서 열리고, 리더 앱이 필요 없고, 그림을 함께 가져가요. 이 변환기는 EPUB 자체의 장에서 자신의 기기에 그 파일을 만들어요.

📚
.epub 파일을 여기에 놓거나, 클릭해서 선택하세요

최대 20 MB 책이에요. 파일은 이 기기에서만 처리돼요 - 업로드되는 것은 없어요.

읽기 순서의 장

    설계상 비공개: 이 도구의 모든 것은 JavaScript로 브라우저에서 100% 일어나요. 파일은 서버에 업로드되지 않고, 저장되지 않고, 저희가 보지 않아요 - 탭을 닫으면 모든 것이 사라져요. DRM으로 보호된 책은 변환할 수 없고 하지 않을 거예요.

    이 도구 사용 방법

    1. 위 상자를 클릭(또는 끌어다 놓기)하고 DRM 없는 것을 선택하세요 .epub 최대 20 MB 파일이에요.
    2. 확인하세요 장 목록 변환 후 표시돼요.
    3. 클릭 .html 파일 다운로드 그리고 모든 브라우저에서 여세요 - 인터넷이나 리더 앱이 필요 없어요.

    작동 방식

    도구는 EPUB Reader와 같은 검증된 파서를 재사용해요: 컨테이너와 패키지(OPF) 파일을 읽고, 읽기 순서를 위해 spine을 따르고, 각 장을 정리해요 (스크립트와 안전하지 않은 마크업이 제거돼요). 책 안에 저장된 이미지는 충분히 작으면(각각 최대 1.5 MB) 데이터 URI로 임베드돼서, 결과는 하나의 파일이에요. 장 사이의 내부 링크는 무력화돼요 - EPUB 밖에 더 이상 존재하지 않는 파일을 가리킬 것이기 때문이에요 - 그리고 장은 책 제목과 저자가 위에 있는 간단하고 읽기 쉬운 타이포그래피로 감싸져요.

    작업 예시

    한 교사가 DRM 없는 수업 읽기자료를 HTML로 변환하고, 단일 파일을 학교 드라이브에 올리면, 모든 학생이 브라우저에서 열어요 - 그림도 포함 - 설치할 것이 없어요.

    자주 묻는 질문

    이 EPUB를 HTML로 변환기가 무료인가요?

    네 - 완전히 무료, 회원가입 없음, 계정 없음, 제한이 없어요.

    제 전자책이 서버에 업로드되나요?

    아니요. 파일은 JavaScript로 브라우저에서 100% 변환돼요. 기기를 떠나지 않고 저희가 저장하지 않아요.

    왜 HTML 파일이 EPUB보다 큰가요?

    그림은 데이터 URI로 파일 안에 임베드돼서 자체적으로 작동해요. 각각 1.5 MB를 넘는 이미지는 파일을 사용 가능하게 유지하기 위해 제외돼요.

    왜 책 안의 링크가 HTML 파일에서 작동하지 않나요?

    내부 링크는 EPUB 안의 별도 장 파일을 가리켜요. 하나의 독립 파일에서는 깨질 것이기 때문에, 무력화돼요; 모든 장이 순서대로 하나의 파일에 있어요.

    왜 제 책이 변환되지 않나요? (DRM)

    Kindle, Kobo, Apple Books 같은 상점에서 산 대부분의 전자책은 DRM으로 보호돼요. 이 도구는 DRM으로 보호된 책을 변환할 수 없고 하지 않을 것이고, DRM을 제거하거나 깨지 않아요.
