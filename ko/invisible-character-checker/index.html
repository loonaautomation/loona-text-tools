보이지 않는 문자 검사기 - 볼 수 없는 문자 보기

요컨대: Invisible Character Checker는 텍스트에서 숨은 문자를 스캔해요 - 너비가 없는 공백, 바이트 순서 표시, 줄 바꿈 없는 공백, 방향 재정의 - 그것들이 정확히 어디에 숨는지 나열하고, 클릭 한 번으로 모두 제거해요.

복사한 텍스트는 종종 보이지 않는 승객을 몰래 들여와요: 웹 페이지의 너비가 없는 공백, Word의 줄 바꿈 없는 공백, 이중 언어 문서의 방향 표시예요. 그것들은 마법처럼 보이는 방식으로 검색, 비밀번호, 코드, 양식 제출을 깨뜨려요. 아래에 텍스트를 붙여 넣고 숨은 문자마다 이름과 위치를 확인하세요.

설계상 비공개: 이 도구의 모든 것은 JavaScript로 브라우저에서 100% 일어나요. 텍스트는 서버에 업로드되지 않고, 저장되지 않고, 저희가 보지 않아요 - 탭을 닫으면 모든 것이 사라져요.

보이지 않는 문자 검사기 사용 방법

  1. 의심스러운 텍스트를 붙여 넣으세요 - 웹 페이지, PDF, Word, 채팅 메시지에서요.
  2. 보고를 읽으세요: 찾은 보이지 않는 문자마다, 그 이름, Unicode 코드, 텍스트에서의 위치예요.
  3. "Remove all invisible characters"를 클릭해 텍스트를 그 자리에서 정리한 다음, 원래 있던 곳에 다시 복사하세요.

작동 방식

Unicode에는 보이는 공간을 차지하지 않는 문자가 많이 있어요: 너비가 없는 공백(U+200B)은 웹 페이지에서 몰래 들어오고, 바이트 순서 표시(U+FEFF)는 저장된 파일에서 따라오고, 줄 바꿈 없는 공백(U+00A0)은 워드 프로세서에서 오고 일반 공백처럼 정확히 보이지만 정확한 검색을 실패하게 하고, 방향 표시(U+202A-U+202E)는 우르두어/아랍어와 영어 텍스트가 섞인 곳에서 몰래 들어와 보이는 것을 재정렬할 수도 있어요. 검사기는 텍스트를 문자별로 따라가고, 각 문자를 알려진 보이지 않는 코드 포인트 목록과 대조하고, 모든 발견 위치를 보고해요. 정리는 줄 바꿈 없는 공백을 일반 공백으로 교체하고 나머지를 삭제해요.

작업 예시

복사한 쿠폰 코드가 결제에서 계속 실패해요. 검사기가 웹 페이지에서 붙여 넣은 위치 7에서 너비가 없는 공백을 찾아요. 클릭 한 번으로 제거하면 - 코드가 작동해요.

자주 묻는 질문

이 보이지 않는 문자 검사기가 무료인가요?

네 - 완전히 무료, 회원가입 없음, 제한이 없어요.

왜 보이지 않는 문자가 중요한가요?

그것들은 동일하게 보이는 텍스트가 정확한 일치를 실패하게 만들어요 - 로그인, 쿠폰 코드, 검색, 해시태그, 코드가 모두 안에 숨은 문자가 있으면 깨져요.

너비가 없는 공백은 어디에서 오나요?

대부분 복사-붙여 넣기예요: 콘텐츠 관리 시스템, 채팅 앱, 문서가 줄 바꿈 힌트로 그것들을 삽입하고, 텍스트와 함께 보이지 않게 따라다녀요.

제 텍스트가 어디에 업로드되나요?

아니요. 스캔은 브라우저에서 100% 일어나요 - 텍스트가 기기를 떠나지 않아요.

정리가 제 텍스트의 모습을 바꾸나요?

아니요 - 그게 핵심이에요. 보이지 않는 문자만 제거돼요 (줄 바꿈 없는 공백은 일반 공백이 돼요). 그래서 보이는 텍스트는 정확히 그대로 남아요.
