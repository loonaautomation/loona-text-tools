CBZ를 PDF로 - 만화 아카이브를 PDF로 변환

요컨대: .cbz 파일(또는 페이지 이미지의 .zip)을 선택하고 깔끔한 PDF를 얻으세요: 페이지마다 전체 크기의 이미지 하나, 자연스럽게 정렬돼요 - 페이지 1, 2, 10 순서예요. 1, 10, 2가 아니에요. 최대 20 MB 아카이브, 기기에서 변환돼요; 업로드되는 것은 없어요.

CBZ는 이름만 다른 스캔한 만화 페이지의 ZIP이에요. 이 도구는 아카이브를 열고, 리더가 기대하는 방식으로 페이지를 정렬하고, pdf-lib로 진짜 PDF를 만들어요 - PDF 도구가 사용하는 같은 라이브러리 - 완전히 브라우저에서요.

📚
.cbz 또는 .zip 만화 파일을 여기에 놓거나, 클릭해서 선택하세요

최대 20 MB 아카이브, 페이지 이미지(.jpg, .png, .gif, .webp, .bmp)로 가득해요. 이 기기에서만 변환돼요 - 업로드되는 것은 없어요.

PDF 순서의 페이지 (자연 순서: 1, 2, 10)

    설계상 비공개: 이 도구의 모든 것은 JavaScript로 브라우저에서 100% 일어나요. 파일은 서버에 업로드되지 않고, 저장되지 않고, 저희가 보지 않아요 - 탭을 닫으면 모든 것이 사라져요. DRM으로 보호된 책은 변환할 수 없고 하지 않을 거예요.

    이 도구 사용 방법

    1. 위 상자를 클릭(또는 끌어다 놓기)하고 선택하세요 .cbz 또는 .zip 최대 20 MB 파일이에요.
    2. 확인하세요 페이지 목록 - PDF에 페이지가 나타나는 정확한 순서예요 (자연 숫자 순서).
    3. 클릭 PDF 다운로드 그리고 모든 PDF 리더에서 여세요.

    작동 방식

    아카이브는 JSZip로 로컬에서 압축이 풀려요. 이미지 파일(.jpg, .png, .gif, .webp, .bmp, .avif)이 수집되고, 다른 모든 것은 무시되고, 이름은 자연 숫자 비교로 정렬돼서 번호가 매겨진 페이지가 읽기 순서로 떨어져요. JPG와 PNG 페이지는 pdf-lib로 직접 임베드돼요; 다른 이미지 형식은 먼저 캔버스에 그려지고 PNG로 임베드돼요. 각 PDF 페이지는 이미지에 정확히 맞춰져서, 잘리거나 늘어나는 것은 없어요.

    작업 예시

    page-1.jpg부터 page-24.jpg까지 이름 붙인 24페이지 스캔은 24페이지 PDF로 변환돼요. page 10이 page 1이 아니라 page 9 뒤에 오고, 모든 페이지가 원래 크기를 유지해요.

    자주 묻는 질문

    이 CBZ를 PDF로 변환기가 무료인가요?

    네 - 완전히 무료, 회원가입 없음, 계정 없음, 제한이 없어요.

    제 만화가 서버에 업로드되나요?

    아니요. 아카이브가 열리고 PDF는 브라우저에서 100% 만들어져요. 파일이 기기를 떠나지 않고 저희가 저장하지 않아요.

    여기서 CBZ와 ZIP의 차이는 무엇인가요?

    이 도구는 없어요 - CBZ 파일은 이미지의 ZIP 아카이브라서, 두 확장자가 모두 허용돼요.

    왜 제 페이지 중 하나가 누락됐나요?

    이미지 파일만 페이지가 될 수 있어요. 브라우저가 디코딩할 수 없는 특이한 형식의 페이지는 PDF를 조용히 깨는 대신 건너뜀으로 나열돼요.

    크기 제한은 무엇인가요?

    최대 20 MB 아카이브를 브라우저에서 처리해요; 더 큰 파일은 명확한 메시지를 받아요.
