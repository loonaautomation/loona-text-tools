EPUB Metadata Editor - Edit an Ebook's Title, Author & Details

In short: choose a DRM-free EPUB to see and edit its metadata - title, author, language, publisher and description - and to see its cover information (cover file and type, with a preview) - and optionally replace the cover image with your own JPG or PNG. Saving downloads a new EPUB with the same chapters and cover and the corrected package (OPF) metadata; the mimetype entry stays first and uncompressed. Your original file is never changed, and DRM-protected books will not be edited.

A wrong title, a missing author or an empty description makes a book hard to find in any library app. This editor reads the book's package file, lets you fix those fields properly, and rebuilds a valid EPUB around the untouched chapters.

How to use this tool

  1. Click the box above (or drag and drop) and choose a DRM-free .epub file up to 20 MB.
  2. Review the cover information and preview, then edit the title, author, language, publisher or description fields.
  3. Click Save Edited EPUB & Download - the new file keeps every chapter exactly as it was.

How it works

Every EPUB carries a package file (the OPF) holding its official metadata as Dublin Core fields. This tool reuses the same tested parser as our EPUB Reader to find that file, shows its fields and the declared cover image, and - when you save - rewrites only those metadata fields, escaping them safely as XML. The book is then rezipped to the EPUB rule: the mimetype entry first and stored uncompressed, every other file (chapters, images, styles) copied byte-for-byte.

Worked example

A teacher receives a scan-converted reader titled “untitled-document-3”. In one minute she sets the real title, her school as publisher and a one-line description, saves, and the book now shelves correctly in every student's reader app.

Frequently Asked Questions

Is this EPUB metadata editor free?

Yes - completely free, with no sign-up, no account and no limit.

Is my ebook uploaded to a server?

No. The file is read and rebuilt 100% in your browser with JavaScript. It never leaves your device and is never stored by us.

Will editing metadata change my chapters or cover?

No. Chapter files, images and styles are copied byte-for-byte; only the metadata fields in the package file change. The cover image itself is shown for reference and is not replaced.

Why won't my book open for editing? (DRM)

Most ebooks bought from stores such as Kindle, Kobo or Apple Books are protected by DRM. This tool will not edit DRM-protected books, and it does not remove or crack DRM.

What is the file size limit?

Books up to 20 MB are handled in the browser. A larger file gets a clear message instead of a broken result.
