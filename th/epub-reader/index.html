โปรแกรมอ่าน EPUB — เปิด & อ่านอีบุ๊ก EPUB ออนไลน์

โดยสรุป: เลือกอีบุ๊ก EPUB จากอุปกรณ์ของคุณและอ่านมันที่นี่ในเบราว์เซอร์ของคุณ — พร้อมรายการบท ขนาดข้อความที่ปรับได้ และธีมมืดสำหรับการอ่านตอนกลางคืน ไฟล์ถูกเปิดบนอุปกรณ์ของคุณเองและไม่เคยถูกอัปโหลดที่ใด ขีดจำกัดที่ซื่อสัตย์หนึ่งข้อ: อีบุ๊กที่ป้องกันด้วย DRM (หนังสือส่วนใหญ่ที่ซื้อจากร้าน Kindle, Kobo หรือ Apple) เปิดไม่ได้ เพราะโปรแกรมอ่านนี้ไม่ลบหรือถอด DRM

EPUB เป็นรูปแบบอีบุ๊กที่พบมากที่สุดในโลก ใช้โดยห้องสมุดสาธารณะ Project Gutenberg และร้านหนังสือส่วนใหญ่นอก Amazon จนถึงตอนนี้คุณต้องมีแอปพิเศษเพื่อเปิดมัน ที่นี่คุณเพียงเลือกไฟล์: โปรแกรมอ่านจะแตกไฟล์ทันที แสดงรายการบท แสดงรูปภาพภายในหนังสือ และให้คุณอ่านอย่างสบายบนโทรศัพท์ แท็บเล็ต หรือคอมพิวเตอร์ทุกเครื่อง

📖
วางไฟล์ .epub ของคุณที่นี่ หรือคลิกเพื่อเลือก

หนังสือเปิดบนอุปกรณ์นี้เท่านั้น — ไม่มีการอัปโหลด และคุณอ่านต่อได้แม้การเชื่อมต่อของคุณหลุด

เป็นส่วนตัวโดยการออกแบบ: ทุกอย่างในเครื่องมือนี้เกิดขึ้น 100% ในเบราว์เซอร์ของคุณด้วย JavaScript อีบุ๊กของคุณไม่เคยถูกอัปโหลดไปยังเซิร์ฟเวอร์ ไม่เคยถูกจัดเก็บ และไม่เคยถูกเห็นโดยเรา — ปิดแท็บแล้วทุกอย่างหายไป

วิธีใช้โปรแกรมอ่าน EPUB

  1. คลิกกล่องด้านบน (หรือลากและวาง) แล้วเลือก .epub ไฟล์จากอุปกรณ์ของคุณ
  2. โปรแกรมอ่านแสดงชื่อเรื่องของหนังสือ ผู้แต่ง และรายการบท เลือกบทใดก็ได้จากรายการเพื่อกระโดดตรงไปหามัน
  3. ใช้ บทก่อนหน้า / บทถัดไป ปุ่มเพื่ออ่านผ่านหนังสือ A− / A+ เพื่อเปลี่ยนขนาดข้อความ และ มืด ปุ่มสำหรับการอ่านตอนกลางคืน
  4. เมื่อคุณเสร็จ เพียงปิดแท็บ — หรือใช้ "Close book" เพื่อเปิดอีบุ๊กเล่มอื่น

วิธีการทำงาน

ไฟล์ EPUB จริง ๆ คือเว็บไซต์ขนาดเล็กที่บีบอัดเป็นไฟล์เดียว: ชุดบทที่เขียนเป็น XHTML พร้อมรูปภาพและแผนที่ของหนังสือ โปรแกรมอ่านนี้จะแตกไฟล์ในเบราว์เซอร์ของคุณ อ่านแผนที่ (ไฟล์แพ็กเกจที่เรียกว่า OPF) เพื่อค้นหาชื่อเรื่อง ผู้แต่ง และลำดับบทที่ถูกต้องของหนังสือ และอ่านสารบัญ — เอกสารนำทางของ EPUB 3 หรือไฟล์ NCX รุ่นเก่าในหนังสือ EPUB 2 จากนั้นแต่ละบทจะถูกทำความสะอาดก่อนแสดง: สคริปต์และทุกอย่างที่อาจรันโค้ดหรือติดต่อกลับบ้านจะถูกถอดออก ขณะที่รูปภาพของหนังสือเองโหลดอย่างปลอดภัยจากภายในไฟล์ เนื่องจากทุกอย่างทำงานในเครื่อง แม้แต่นิยายเล่มใหญ่ก็เปิดได้ภายในหนึ่งหรือสองวินาที

ตัวอย่างที่ทำแล้ว

คุณดาวน์โหลดนิยายสาธารณสมบัติฟรีจาก Project Gutenberg แล้วเปิดที่นี่ โปรแกรมอ่านแสดงชื่อเรื่องและผู้แต่ง แสดงรายการ 24 บททั้งหมด และเปิดบทที่ 1 บนรถบัสคุณแตะ "Next chapter" เพื่ออ่านต่อ ขยายข้อความครั้งหนึ่ง และเปิดธีมมืดเมื่อข้างนอกเริ่มมืด — ไม่มีการติดตั้งแอป ไม่มีการสร้างบัญชี และไฟล์ไม่เคยออกจากโทรศัพท์ของคุณ

คำถามที่พบบ่อย

โปรแกรมอ่าน EPUB นี้ฟรีหรือไม่?

ใช่ — ฟรีอย่างสมบูรณ์ ไม่ต้องสมัครสมาชิก ไม่มีบัญชี และไม่มีขีดจำกัดจำนวนอีบุ๊กที่คุณเปิด

อีบุ๊กของฉันถูกอัปโหลดไปยังเซิร์ฟเวอร์หรือไม่?

ไม่ ไฟล์ถูกเปิดและอ่าน 100% ในเบราว์เซอร์ของคุณด้วย JavaScript มันไม่ออกจากอุปกรณ์ของคุณเลย เราไม่เคยจัดเก็บ และทำงานได้แม้คุณออฟไลน์หลังจากหน้าโหลดเสร็จ

ทำไมอีบุ๊กของฉันจึงเปิดไม่ได้? (DRM)

อีบุ๊กส่วนใหญ่ที่ซื้อจากร้านอย่าง Kindle, Kobo หรือ Apple Books ได้รับการคุ้มครองโดย DRM (การป้องกันการคัดลอก) โปรแกรมอ่านนี้เปิดไฟล์ที่คุ้มครองด้วย DRM ไม่ได้ และมันไม่ลบหรือถอด DRM ไฟล์ EPUB ที่ไม่มี DRM — ตัวอย่างเช่น หนังสือสาธารณสมบัติจาก Project Gutenberg หรือหนังสือที่สำนักพิมพ์ขายแบบไม่มี DRM — เปิดได้ตามปกติ

รองรับ EPUB เวอร์ชันใดบ้าง?

ทั้ง EPUB 2 และ EPUB 3 โปรแกรมอ่านเข้าใจเอกสารนำทางของ EPUB 3 และไฟล์ NCX รุ่นเก่าในหนังสือ EPUB 2 และแสดงรูปภาพที่เก็บอยู่ภายในหนังสือ

ฉันอ่านบนโทรศัพท์หรือแท็บเล็ตได้ไหม?

ใช่ โปรแกรมอ่านตอบสนองได้อย่างสมบูรณ์ และคุณสามารถขยายข้อความและสลับเป็นธีมมืดเพื่อการอ่านตอนกลางคืนที่สบายบนหน้าจอทุกขนาด
