ข้อความ / Markdown เป็น EPUB — สร้างอีบุ๊ก EPUB ของคุณเอง

โดยสรุป: วางหรืออัปโหลดข้อความธรรมดาหรือ Markdown เพิ่มชื่อเรื่องและผู้แต่ง แล้วดาวน์โหลดอีบุ๊ก EPUB ที่ถูกต้อง — โครงสร้างที่ถูกต้อง (mimetype ก่อนและไม่บีบอัด container ไฟล์แพ็กเกจ เอกสารนำทาง และ NCX) บทแยกตามหัวข้อ Markdown พร้อมการจัดรูปแบบ Markdown พื้นฐาน (หัวข้อ ตัวหนา ตัวเอียง รายการ และย่อหน้า) คงอยู่ ผลลัพธ์เปิดใน EPUB Reader ของเราเองและในโปรแกรมอ่านอีบุ๊กมาตรฐาน

นักเขียน ครู และนักเรียนมักมีข้อความที่เสร็จแล้วแต่ไม่มีอีบุ๊ก ตัวสร้างนี้เปลี่ยนข้อความนั้นให้เป็น EPUB จริง — ไม่ใช่ zip ที่เปลี่ยนชื่อ — โดยใช้กฎพอดีที่โปรแกรมอ่านอีบุ๊กคาดหวัง ทั้งหมดบนอุปกรณ์ของคุณ

บทที่สร้างแล้ว

    เป็นส่วนตัวโดยการออกแบบ: ทุกอย่างในเครื่องมือนี้เกิดขึ้น 100% ในเบราว์เซอร์ของคุณด้วย JavaScript ไฟล์ของคุณไม่เคยถูกอัปโหลดไปยังเซิร์ฟเวอร์ ไม่เคยถูกจัดเก็บ และไม่เคยถูกเห็นโดยเรา — ปิดแท็บแล้วทุกอย่างหายไป หนังสือที่ป้องกันด้วย DRM ไม่สามารถและจะไม่ถูกแปลง

    วิธีใช้เครื่องมือนี้

    1. วางข้อความของคุณ ลงในกล่อง หรืออัปโหลด .txt / .md ไฟล์ (สูงสุด 20 MB)
    2. เพิ่ม ชื่อเรื่อง และ ถ้าคุณชอบ ผู้แต่ง. ให้ติ๊ก Markdown ไว้สำหรับข้อความ .md: หัวข้อ # และ ## จะเริ่มบทใหม่. สำหรับข้อความธรรมดา บทจะเริ่มต้นที่บรรทัดอย่างเช่น “Chapter 2” และย่อหน้าจะแยกกันด้วยบรรทัดว่าง
    3. คลิก สร้าง EPUB & ดาวน์โหลด, ตรวจสอบรายการบท และเปิดไฟล์ในโปรแกรมอ่าน EPUB ใดก็ได้ รวมถึงโปรแกรมอ่าน EPUB ฟรีของเรา

    วิธีการทำงาน

    ตัวสร้างประกอบ EPUB ในลำดับเดียวที่มาตรฐานอนุญาต: รายการ mimetype เข้าไปใน zip ก่อนและไม่บีบอัด จากนั้น META-INF/container.xml ชี้ไปที่ไฟล์แพ็กเกจ (OPF) พร้อมชื่อเรื่อง ผู้แต่ง รายการเนื้อหา และลำดับการอ่าน (สันหนังสือ) มันเขียนทั้งเอกสารนำทางของ EPUB 3 และสารบัญ NCX รุ่นเก่า เพื่อให้โปรแกรมอ่านเก่าและใหม่ทำงานได้ทั้งคู่ บวกหน้าชื่อเรื่องและไฟล์ XHTML หนึ่งไฟล์ต่อบท Markdown ถูกแปลงอย่างปลอดภัย — ข้อความของคุณถูกหลบหลีกก่อน จากนั้นหัวข้อ ตัวหนา ตัวเอียง รายการ คำพูด และย่อหน้าถูกเปลี่ยนเป็น XHTML ที่สะอาด

    ตัวอย่างที่ทำแล้ว

    ครูวางเอกสารอ่านประกอบชั้นเรียนที่เขียนด้วย Markdown จำนวน 6 บท ตั้งชื่อว่า “Class 6 Geography Notes” และดาวน์โหลด EPUB หนึ่งไฟล์ นักเรียนเปิดใน Loona EPUB Reader บนโทรศัพท์ — รายการบท หัวข้อ และคำศัพท์สำคัญตัวหนาทั้งหมดยังคงอยู่

    คำถามที่พบบ่อย

    ตัวแปลงข้อความเป็น EPUB นี้ฟรีหรือไม่?

    ใช่ — ฟรีอย่างสมบูรณ์ ไม่ต้องสมัครสมาชิก ไม่มีบัญชี และไม่มีขีดจำกัด

    ข้อความของฉันถูกอัปโหลดไปยังเซิร์ฟเวอร์หรือไม่?

    ไม่ EPUB ถูกสร้าง 100% ในเบราว์เซอร์ของคุณด้วย JavaScript ข้อความของคุณไม่ออกจากอุปกรณ์ของคุณเลยและเราไม่เคยจัดเก็บ

    บทถูกกำหนดอย่างไร?

    ในโหมด Markdown บรรทัดที่ขึ้นต้นด้วย # หรือ ## จะเริ่มบทใหม่ ในโหมดข้อความธรรมดา บรรทัดอย่าง 'Chapter 2' จะเริ่มบทใหม่ และย่อหน้าแยกกันด้วยบรรทัดว่าง หากไม่มีบรรทัดบท ข้อความทั้งหมดจะกลายเป็นบทเดียว

    รองรับ Markdown ใดบ้าง?

    หัวข้อ (## และต่ำกว่าในบท, # / ## เป็นตัวแบ่งบท) ตัวหนา ตัวเอียง รายการแบบจุดและลำดับเลข บล็อกคำพูด โค้ดในบรรทัด และลิงก์เว็บแบบง่าย ตารางที่ซับซ้อนและรูปภาพไม่รองรับ

    EPUB จะเปิดในโปรแกรมอ่านจริงหรือไม่?

    ใช่ มันทำตามโครงสร้าง EPUB — mimetype ก่อนและเก็บไม่บีบอัด container.xml รายการ OPF และสันหนังสือ เอกสารนำทางของ EPUB 3 บวก NCX — และมันถูกทดสอบให้เปิดใน EPUB Reader ของเราเองบนเว็บไซต์นี้

    ขีดจำกัดขนาดคือเท่าใด?

    ข้อความหรือไฟล์ขนาดสูงสุด 20 MB จัดการได้ในเบราว์เซอร์ ข้อมูลที่ใหญ่กว่าจะได้รับข้อความที่ชัดเจน
