ตัวนับคำ - นับคำ ตัวอักษร และเวลาอ่าน

โดยสรุป: ตัวนับคำนับคำ ตัวอักษร ประโยค และย่อหน้าในข้อความของคุณขณะที่คุณพิมพ์ และประมาณว่ามันใช้เวลาอ่านหรือพูดออกเสียงนานแค่ไหน

เรียงความ สุนทรพจน์ โพสต์บล็อก และแบบฟอร์มใบสมัครทั้งหมดมาพร้อมขีดจำกัดคำ วางหรือพิมพ์ข้อความของคุณด้านล่าง แล้วทุกจำนวนจะอัปเดตแบบสด — ไม่มีปุ่มให้กด ไม่มีการอัปโหลด และการประมาณเวลาอ่านและเวลาพูดช่วยให้คุณวางแผนการนำเสนอและวิดีโอ

ตัวนับตัวอักษร Twitter / X ฟรี

โดยสรุป: โพสต์ X อนุญาต 280 ตัวอักษร ทุกลิงก์นับเป็น 23 ตัวอักษร (t.co) และอีโมจิส่วนใหญ่นับเป็น 2

วางข้อความตัวนับตัวอักษร twitter / x ของคุณแล้วดูการนับตัวอักษรแบบสด — พร้อมขีดจำกัดของแพลตฟอร์มและจำนวนตัวอักษรที่คุณเหลืออยู่พอดี

เป็นส่วนตัวโดยการออกแบบ: ทุกอย่างในเครื่องมือนี้เกิดขึ้น 100% ในเบราว์เซอร์ของคุณด้วย JavaScript ข้อความของคุณไม่เคยถูกอัปโหลดไปยังเซิร์ฟเวอร์ ไม่เคยถูกจัดเก็บ และไม่เคยถูกเห็นโดยเรา

เกี่ยวกับเครื่องมือนี้

X (Twitter) อนุญาต 280 ตัวอักษรต่อโพสต์ และการนับไม่ง่ายอย่างที่เห็น: ทุกลิงก์ถูกย่อโดย t.co และนับเป็นพอดี 23 ตัวอักษรไม่ว่าจะยาวแค่ไหน และอีโมจิส่วนใหญ่นับเป็น 2 รูปภาพ วิดีโอ และโพลไม่นับ

กฎปฏิบัติสำหรับโพสต์สั้นคือตั้งเป้า 240 ตัวอักษร เว้นที่ไว้สำหรับลิงก์หนึ่งลิงก์ — และพูดสิ่งนั้นครั้งเดียวให้กระชับ โพสต์ที่ดีที่สุดบนแพลตฟอร์มแทบไม่เคยเป็นโพสต์ที่ยาวที่สุด

ตัวอย่างที่ทำแล้ว

คำถามที่พบบ่อย

ลิงก์และอีโมจีนับหรือไม่?

มันขึ้นอยู่กับแพลตฟอร์ม — บันทึกในหน้านี้ครอบคลุมกฎทั่วไป (ตัวอย่างเช่น X นับทุกลิงก์เป็น 23 ตัวอักษร) อีโมจิมักนับเป็นหนึ่งหรือสองตัวอักษรขึ้นอยู่กับแพลตฟอร์ม

จะเกิดอะไรขึ้นถ้าฉันเกินขีดจำกัด?

แพลตฟอร์มส่วนใหญ่บล็อกการโพสต์ หรือตัดข้อความ ตัวนับจะเปลี่ยนเป็นสีแดงและแสดงว่าต้องตัดกี่ตัวอักษรพอดี

ข้อความของฉันเป็นส่วนตัวหรือไม่?

ใช่ — การนับเกิดขึ้นทั้งหมดในเบราว์เซอร์ของคุณ ไม่มีการอัปโหลดหรือจัดเก็บอะไร

ลิงก์นับเป็น 23 ตัวอักษรจริงหรือ?

ใช่ — X ห่อทุกลิงก์ใน t.co และทุกลิงก์ t.co นับเป็น 23 ตัวอักษรใน 280 ไม่ว่า URL ต้นฉบับจะยาวแค่ไหน

เครื่องมือข้อความที่เกี่ยวข้อง

Tตัวนับตัวอักษรตัวอักษรมีและไม่มีช่องว่าง แบบสดTตัวนับคำนับคำ ตัวอักษร ประโยค และเวลาอ่านTตัวสร้าง Slugเปลี่ยนชื่อเรื่องให้เป็น slug URL ที่สะอาดTตัวคำนวณเวลาอ่านข้อความใช้เวลาอ่านนานแค่ไหน

ฝังเครื่องมือนี้บนเว็บไซต์ของคุณ — ฟรี

เพิ่มเครื่องมือนี้ลงในเว็บไซต์หรือบล็อกของคุณเอง — ฟรีทั้งหมด ไม่ต้องสมัครสมาชิก และแสดงเวอร์ชันล่าสุดเสมอ คัดลอกโค้ดด้านล่างและวางลงในหน้าของคุณตรงตำแหน่งที่ต้องการให้เครื่องมือปรากฏ การคงบรรทัดเครดิตเล็ก ๆ “Powered by Loona Automation” ไว้ใต้ตัวฝังช่วยทำให้เครื่องมือนี้ยังคงฟรี — แต่คุณมีอิสระที่จะจัดรูปแบบหรือลบออก เครื่องมือทำงานได้ทั้งสองแบบ
