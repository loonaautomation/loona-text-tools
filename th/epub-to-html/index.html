EPUB เป็น HTML — แปลงอีบุ๊ก EPUB เป็นไฟล์ HTML เดียว

โดยสรุป: เลือก EPUB ที่ไม่มี DRM แล้วได้ไฟล์ HTML ไฟล์เดียวที่ครบในตัวเอง: บทตามลำดับการอ่านพร้อมตัวอักษรพื้นฐานที่สะอาด รูปภาพเล็ก ๆ ฝังอยู่ภายในไฟล์เป็น data URI และลิงก์หนังสือภายในถูกทำให้เป็นกลางเพื่อไม่ให้อะไรชี้ไปยังไฟล์ที่หายไป หนังสือสูงสุด 20 MB หนังสือที่ป้องกันด้วย DRM ไม่สามารถและจะไม่ถูกแปลง

ไฟล์ HTML เดียวเป็นวิธีที่ง่ายที่สุดในการแชร์หรือเก็บชุดบทของหนังสือ: มันเปิดในทุกเบราว์เซอร์ ไม่ต้องมีแอปอ่าน และพกพารูปภาพไปด้วย ตัวแปลงนี้สร้างไฟล์นั้นบนอุปกรณ์ของคุณเองจากบทของ EPUB เอง

📚
วางไฟล์ .epub ของคุณที่นี่ หรือคลิกเพื่อเลือก

หนังสือขนาดสูงสุด 20 MB ไฟล์ถูกประมวลผลบนอุปกรณ์นี้เท่านั้น — ไม่มีการอัปโหลดใด ๆ

บทตามลำดับการอ่าน

    เป็นส่วนตัวโดยการออกแบบ: ทุกอย่างในเครื่องมือนี้เกิดขึ้น 100% ในเบราว์เซอร์ของคุณด้วย JavaScript ไฟล์ของคุณไม่เคยถูกอัปโหลดไปยังเซิร์ฟเวอร์ ไม่เคยถูกจัดเก็บ และไม่เคยถูกเห็นโดยเรา — ปิดแท็บแล้วทุกอย่างหายไป หนังสือที่ป้องกันด้วย DRM ไม่สามารถและจะไม่ถูกแปลง

    วิธีใช้เครื่องมือนี้

    1. คลิกกล่องด้านบน (หรือลากและวาง) แล้วเลือกไฟล์แบบไม่มี DRM .epub ไฟล์สูงสุด 20 MB
    2. ตรวจสอบ รายการบท แสดงหลังการแปลง
    3. คลิก ดาวน์โหลดไฟล์ .html และเปิดมันในเบราว์เซอร์ใดก็ได้ — ไม่ต้องใช้อินเทอร์เน็ตหรือแอปโปรแกรมอ่าน

    วิธีการทำงาน

    เครื่องมือใช้ตัวแยกวิเคราะห์ที่ผ่านการทดสอบตัวเดียวกันกับ EPUB Reader ของเรา: มันอ่าน container และไฟล์แพ็กเกจ (OPF) ทำตามสันหนังสือสำหรับลำดับการอ่าน และทำความสะอาดแต่ละบท (สคริปต์และมาร์กอัปที่ไม่ปลอดภัยถูกถอดออก) รูปภาพที่เก็บไว้ภายในหนังสือถูกฝังเป็น data URI เมื่อพวกมันเล็กพอ (สูงสุด 1.5 MB แต่ละรูป) ผลลัพธ์จึงเป็นไฟล์เดียว ลิงก์ภายในระหว่างบทถูกทำให้เป็นกลาง — พวกมันจะชี้ไปยังไฟล์ที่ไม่มีอยู่อีกต่อไปนอก EPUB — และบทถูกห่อด้วยตัวอักษรที่เรียบง่ายและอ่านง่าย พร้อมชื่อเรื่องและผู้แต่งของหนังสือที่ด้านบน

    ตัวอย่างที่ทำแล้ว

    ครูแปลงเอกสารอ่านประกอบชั้นเรียนที่ไม่มี DRM เป็น HTML วางไฟล์เดียวนั้นบนไดรฟ์ของโรงเรียน และนักเรียนทุกคนเปิดในเบราว์เซอร์ — รูปภาพรวมอยู่ด้วย — โดยไม่ต้องติดตั้งอะไรเลย

    คำถามที่พบบ่อย

    ตัวแปลง EPUB เป็น HTML นี้ฟรีหรือไม่?

    ใช่ — ฟรีอย่างสมบูรณ์ ไม่ต้องสมัครสมาชิก ไม่มีบัญชี และไม่มีขีดจำกัด

    อีบุ๊กของฉันถูกอัปโหลดไปยังเซิร์ฟเวอร์หรือไม่?

    ไม่ ไฟล์ถูกแปลง 100% ในเบราว์เซอร์ของคุณด้วย JavaScript มันไม่ออกจากอุปกรณ์ของคุณเลยและเราไม่เคยจัดเก็บ

    ทำไมไฟล์ HTML จึงใหญ่กว่า EPUB?

    รูปภาพถูกฝังอยู่ภายในไฟล์เป็น data URI เพื่อให้มันทำงานได้ด้วยตัวเอง รูปภาพที่เกิน 1.5 MB ต่อรูปจะถูกละไว้เพื่อให้ไฟล์ใช้งานได้

    ทำไมลิงก์ภายในหนังสือจึงไม่ทำงานในไฟล์ HTML?

    ลิงก์ภายในชี้ไปที่ไฟล์บทแยกกันภายใน EPUB ในไฟล์เดี่ยวที่สมบูรณ์ พวกมันจะเสีย จึงถูกทำให้เป็นกลาง บททั้งหมดอยู่ครบ ตามลำดับ ในไฟล์เดียว

    ทำไมหนังสือของฉันจึงแปลงไม่ได้? (DRM)

    อีบุ๊กส่วนใหญ่ที่ซื้อจากร้านอย่าง Kindle, Kobo หรือ Apple Books ได้รับการคุ้มครองโดย DRM เครื่องมือนี้แปลงหนังสือที่คุ้มครองด้วย DRM ไม่ได้และจะไม่แปลง และมันไม่ลบหรือถอด DRM

    EPUB เป็นข้อความ

    เปลี่ยนอีบุ๊ก EPUB ให้เป็นไฟล์ข้อความธรรมดาที่สะอาด บทตามลำดับการอ่าน

    📕

    ข้อความ / Markdown เป็น EPUB

    เปลี่ยนข้อความธรรมดาหรือ Markdown ให้เป็นอีบุ๊ก EPUB ที่เหมาะสมที่คุณอ่านได้ในโปรแกรมอ่านใดก็ได้

    📖

    โปรแกรมอ่าน EPUB

    เปิดและอ่านอีบุ๊ก EPUB ตรงในเบราว์เซอร์ของคุณ — รายการบทและโหมดมืด

    🏷️

    ตัวแก้ไขเมทาดาทา EPUB

    แก้ไขชื่อเรื่อง ผู้แต่ง และคำอธิบายของอีบุ๊ก — บทไม่ถูกแตะต้อง
