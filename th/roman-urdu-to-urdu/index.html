ตัวแปลงอักษรโรมันอูรดูเป็นอูรดู

โดยสรุป: ตัวแปลงอูรดูโรมันเปลี่ยนอูรดูที่เขียนด้วยตัวอักษรอังกฤษ ('mera naam Ahmed hai') ให้เป็นอักษรอูรดูที่ถูกต้อง (میرا نام احمد ہے) — ทันทีและฟรี

ชาวปากีสถานหลายล้านคนพิมพ์อูรดูด้วยตัวอักษรภาษาอังกฤษทุกวันเพราะแป้นพิมพ์อูรดูรู้สึกช้า — แต่โรมันอูรดูดูไม่เป็นมืออาชีพในเอกสาร งานมอบหมาย และข้อความทางการ พิมพ์หรือวางโรมันอูรดูของคุณที่นี่แล้วรับอักษรอูรดูที่สะอาดและถูกต้องที่คุณคัดลอกได้ทุกที่

เป็นส่วนตัวโดยการออกแบบ: ทุกอย่างในเครื่องมือนี้เกิดขึ้น 100% ในเบราว์เซอร์ของคุณด้วย JavaScript ข้อความของคุณไม่เคยถูกอัปโหลดไปยังเซิร์ฟเวอร์ ไม่เคยถูกจัดเก็บ และไม่เคยถูกเห็นโดยเรา — ปิดแท็บแล้วทุกอย่างหายไป

วิธีใช้โรมันอูรดูเป็นอูรดู

  1. พิมพ์หรือวางอูรดูโรมันของคุณลงในกล่องแรก
  2. คลิก แปลง — คำอูรดูทั่วไปจะกลายเป็นอักษรที่ถูกต้องพอดี
  3. คัดลอกข้อความอูรดูลงใน Word, WhatsApp งานมอบหมายของคุณ หรือที่ใดก็ได้

วิธีการทำงาน

การสะกดภาษาอูรดูไม่สามารถเดาตัวอักษรต่อตัวอักษรจากการเขียนโรมันได้ — 'hai' คือ ہے ไม่ใช่การสะกดตามเสียง ดังนั้นตัวแปลงนี้ก่อนอื่นจับคู่ทุกคำกับพจนานุกรมในตัวของคำ ชื่อ และวลีภาษาอูรดูที่พบบ่อยที่สุด — คำที่ประกอบเป็นประโยคประจำวัน — และแปลงคำเหล่านั้นอย่างพอดี คำที่อยู่นอกพจนานุกรมถูกถอดเสียงตามเสียงโดยใช้กฎตัวอักษรอูรดู (kh → کھ, sh → ش, ch → چ และอื่น ๆ) เครื่องหมายวรรคตอนก็ถูกแปลงเช่นกัน: มหัพภาคกลายเป็น ۔ และเครื่องหมายคำถามกลายเป็น ؟ ประโยคประจำวันแปลงได้เกือบสมบูรณ์ ให้ชื่อที่ไม่ธรรมดาหรือคำที่หายากมองผ่านอย่างรวดเร็วก่อนส่ง

ตัวอย่างที่ทำแล้ว

คุณพิมพ์: 'Assalam-o-Alaikum, mera naam Ahmed hai. Main school mein ustad hoon aur mujhe taleem se mohabbat hai.' ผลลัพธ์: 'السلام علیکم، میرا نام احمد ہے۔ میں اسکول میں استاد ہوں اور مجھے تعلیم سے محبت ہے۔' — พร้อมสำหรับข้อความทางการ

คำถามที่พบบ่อย

ตัวแปลงโรมันอูรดูฟรีหรือไม่?

ใช่ — ฟรีอย่างสมบูรณ์ ไม่ต้องสมัครสมาชิก ใช้ได้บ่อยเท่าที่คุณต้องการ

มันแม่นยำแค่ไหน?

ประโยคในชีวิตประจำวันที่สร้างจากคำทั่วไปแปลงได้เกือบพอดี เพราะคำเหล่านั้นมาจากพจนานุกรมจริง คำที่หายากและชื่อที่ไม่ธรรมดาจะถูกออกเสียงทีละตัวอักษรและอาจต้องแก้เล็กน้อย

มันแปลงอักษรอูรดูกลับเป็นโรมันได้ไหม?

ยังไม่ — เครื่องมือนี้แปลงโรมันอูรดูเป็นอักษรอูรดู ซึ่งเป็นทิศทางที่คนต้องการสำหรับเอกสารและข้อความทางการ

มันแก้คำสะกดผิดของฉันหรือไม่?

ไม่ — มันแปลงสิ่งที่คุณพิมพ์ หากคำโรมันสะกดผิด ('mujhy' แทนที่จะเป็น 'mujhe') พจนานุกรมอาจหาไม่พบและออกเสียงแทน

ข้อความของฉันถูกอัปโหลดหรือไม่?

ไม่ — การแปลงทำงาน 100% ในเบราว์เซอร์ของคุณบนอุปกรณ์ของคุณ
