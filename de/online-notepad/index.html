Online-Notizblock – Speichert automatisch, während Sie tippen

Kurz gesagt: der Online-Notizblock speichert Ihre Notiz automatisch in Ihrem eigenen Browser, während Sie tippen, sodass sie noch hier ist, wenn Sie zurückkommen – mit eingebautem Download und Drucken.

Für schnelle Notizen, Entwürfe und Listen sollten Sie kein Konto oder eine App-Installation brauchen. Öffnen Sie diese Seite und tippen Sie: Ihre Notiz speichert sich in jedem Moment selbst auf diesem Gerät, überlebt das Schließen des Tabs und kann heruntergeladen oder gedruckt werden, wann immer Sie bereit sind.

Bereit.
Privat von Natur aus: alles in diesem Tool geschieht zu 100 % in Ihrem Browser mit JavaScript. Ihr Text wird nie auf einen Server hochgeladen, nie gespeichert und nie von uns gesehen – schließen Sie den Tab, und alles ist weg.

So verwenden Sie den Online-Notizblock

  1. Beginnen Sie einfach zu tippen – die Notiz speichert sich automatisch auf diesem Gerät, während Sie schreiben.
  2. Schließen Sie den Tab und kommen Sie jederzeit zurück: Ihre Notiz wartet genau so, wie Sie sie gelassen haben.
  3. Laden Sie es als Textdatei herunter oder drucken Sie es, wenn Sie es außerhalb des Browsers brauchen.

So funktioniert es

Der Notizblock verwendet den eigenen lokalen Speicher Ihres Browsers – ein kleines privates Regal im Browser auf Ihrem Gerät. Jede Änderung wird dort innerhalb einer Sekunde geschrieben, unter dem eigenen Schlüssel dieser Seite. Nichts reist zu irgendeinem Server, weshalb der Notizblock offline funktioniert und weshalb Ihre Notizen von uns oder sonst jemandem nicht gesehen werden können. Ein ehrliches Limit: Lokaler Speicher gehört zu diesem Browser auf diesem Gerät – das Löschen von Browserdaten löscht ihn, also laden Sie alles Kostbare herunter.

Durchgearbeitetes Beispiel

Eine Lehrerin entwirft tagsüber die Quizfragen für morgen und fügt eine Frage hinzu, wann immer ihr eine einfällt. Der Tab wird zweimal versehentlich geschlossen – kein Problem: Jedes Mal, wenn sie zurückkehrt, ist jede Frage genau dort, wo sie sie gelassen hat, bereit zum Herunterladen am Abend.

Häufig gestellte Fragen

Ist der Online-Notizblock kostenlos?

Ja – kostenlos, keine Registrierung, kein Speicherlimit jenseits des eigenen Kontingents Ihres Browsers.

Wo wird meine Notiz gespeichert?

Nur in diesem Browser auf diesem Gerät (lokaler Speicher). Es wird nie hochgeladen, synchronisiert oder für uns sichtbar.

Überlebt meine Notiz das Schließen des Tabs?

Ja – das ist der Sinn des automatischen Speicherns. Es überlebt Tab-Schließungen und Browser-Neustarts auf demselben Gerät.

Was kann meine Notiz löschen?

Das Löschen der Browserdaten dieser Seite, die Verwendung eines anderen Browsers oder Geräts oder das Drücken von 'Neue Notiz'. Laden Sie eine Kopie von allem Wichtigen herunter.

Kann ich es offline verwenden?

Ja – nachdem die Seite einmal geladen hat, funktionieren Tippen und Speichern vollständig offline.
