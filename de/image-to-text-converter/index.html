Bild-zu-Text-Konverter - Text aus einem Bild extrahieren (OCR)

Kurz gesagt: laden Sie ein Foto oder einen Scan hoch, und dieses kostenlose OCR-Tool zieht die gedruckten Wörter als bearbeitbaren Text heraus – vollständig in Ihrem Browser, sodass Ihr Bild nie irgendwohin hochgeladen wird.

Notizen an einem Whiteboard, ein Absatz in einem gedruckten Buch, ein Screenshot voller Text, den Sie zitieren müssen – erneutes Tippen ist langsam und fehleranfällig. Wählen Sie unten ein Bild, und der erkannte Text erscheint im Feld, bereit zum Bearbeiten, Kopieren oder Herunterladen. Diese Version liest Englisch; die erste Umwandlung lädt die englischen Sprachdaten (etwa 11 MB) von dieser Website herunter, und Ihr Browser speichert sie für das nächste Mal zwischen.

Privat von Natur aus: die OCR-Engine (Tesseract.js) ist auf dieser Website gespeichert und läuft zu 100 % in Ihrem Browser. Ihr Bild wird nie auf einen Server hochgeladen, nie gespeichert und nie von uns gesehen – schließen Sie den Tab, und alles ist weg.

So verwenden Sie den Bild-zu-Text-Konverter

  1. Wählen Sie eine Bilddatei – einen Scan, Screenshot oder ein Foto mit gedrucktem Text. Sie können die Datei auch auf das Feld ziehen und ablegen.
  2. Drücken Sie Text extrahieren. Beim ersten Mal lädt Ihr Browser die englischen Sprachdaten herunter (etwa 11 MB); danach werden sie zwischengespeichert und Umwandlungen gehen schnell.
  3. Beobachten Sie den Fortschrittsprozentsatz, dann bearbeiten Sie das Ergebnis bei Bedarf direkt im Feld.
  4. Kopieren Sie den Text, oder laden Sie ihn als .txt-Datei herunter.

So funktioniert es

OCR (optische Zeichenerkennung) scannt die Formen in Ihrem Bild und gleicht sie mit einem trainierten Modell gedruckter Zeichen ab. Dieses Tool verwendet Tesseract.js, die Browser-Version der bekannten Open-Source-Tesseract-Engine, mit ihrem englischen LSTM-Modell. Alles – die Engine und die Sprachdaten – wird von dieser Website bereitgestellt und von Ihrem eigenen Browser ausgeführt, also reisen keine Bilddaten je zu einem Server. Klarer, flacher, gut beleuchteter gedruckter Text ergibt die besten Ergebnisse; Handschrift, verspielte Display-Schriften und komplizierte Tabellen mit zusammengeführten Zellen werden weniger zuverlässig erkannt, also lohnt sich ein schnelles Korrekturlesen immer.

Durchgearbeitetes Beispiel

Sie fotografieren einen gedruckten Schulhinweis über ein Elterntreffen. Das Tool extrahiert in wenigen Sekunden 214 Wörter – Treffdatum, Zeit und Ort alle korrekt – und Sie fügen den Text direkt in eine Nachricht ein, statt den ganzen Hinweis von Hand zu tippen. Ein unscharfes Wort im Foto kam falsch heraus und brauchte eine Ein-Buchstaben-Korrektur, was typisch ist: schnell, und einen schnellen Blick wert.

Häufig gestellte Fragen

Wird mein Bild auf einen Server hochgeladen?

Nein. Die OCR-Engine (Tesseract.js) ist auf dieser Website gespeichert und läuft vollständig in Ihrem Browser. Ihr Bild verlässt Ihr Gerät nie, und nichts wird an uns oder Dritte gesendet.

Warum dauert die erste Umwandlung länger?

Bei der ersten Verwendung lädt Ihr Browser die englischen Sprachdaten (etwa 11 MB) von dieser Website herunter. Ihr Browser speichert sie zwischen, also starten spätere Umwandlungen fast sofort und funktionieren sogar offline.

Welche Sprachen werden unterstützt?

Diese Version erkennt englischen Text. Mehr Sprachen sind für ein zukünftiges Update geplant.

Wie genau ist das Ergebnis?

Auf klarem gedrucktem Text – Scans, Screenshots und scharfen Fotos – liegt die Genauigkeit typischerweise bei 95 % oder besser. Handschrift, dekorative Schriften, schlechtes Licht und komplexe Tabellen mit zusammengeführten Zellen sind schwieriger und brauchen möglicherweise manuelle Korrektur, also lesen Sie wichtige Dokumente immer Korrektur.

Welche Bildformate kann ich verwenden?

PNG-, JPG- (JPEG-), WebP- und BMP-Dateien funktionieren alle. Für beste Ergebnisse verwenden Sie ein gerades, gut beleuchtetes Bild, bei dem der Text horizontal und so groß wie möglich ist.
